# Pawlitics

Eine gemütliche Cartoon-Politiksimulation, in der eine Stadt voller Tiere auf jede Entscheidung reagiert

Bramblewood braucht eine Gouverneurin oder einen Gouverneur. Wie wäre es mit Ihnen?

Pawlitics ist eine gemütliche Politiksimulation im Cartoon-Stil. Wählen Sie eine Gouverneurin oder einen Gouverneur, legen Sie die Politik fest und sehen Sie zu, wie eine Stadt voller Tiere reagiert: Bären mit Schutzhelm, Hühner mit Fliege und Mäuse, die in Schuhkartons wohnen und finden, dass es dort eigentlich ganz schön ist.
