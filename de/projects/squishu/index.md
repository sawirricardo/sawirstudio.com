# Squishu

Quetschen Sie Dumplings. Besiegen Sie den Boss, bevor der Dampf verflogen ist.

Squishu ist ein niedliches Clicker-Spiel rund ums Quetschen von Essen. Tippen Sie auf Dumplings, Onigiri, Sushi, Mochi, Boba und mehr, bis sie platzen, und stellen Sie sich dann dem Boss jeder Welt, bevor dessen Timer abläuft. Heuern Sie eine Truppe von Dumpling-Freunden an, die auch in Ihrer Abwesenheit weiterquetschen, und kehren Sie zu einem Dampfkorb voller Münzen zurück.
