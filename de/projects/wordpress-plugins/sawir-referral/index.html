Sawir Referral

Mit Sawir Referral bringen Ihre Kunden ihre Freunde mit. Der Freund erhält einen Rabatt, der Kunde, der empfohlen hat, verdient einen Belohnungs-Gutschein, und geteilt wird per Code, per Link oder direkt über WhatsApp.

Kostenlos auf WordPress.org herunterladen

Was es kann

Machen Sie Ihre Kunden zu Ihrem Vertriebskanal. Jeder Kunde erhält auf seiner Seite „Mein Konto“ einen persönlichen Empfehlungscode (ein echter WooCommerce-Gutschein) und einen Link zum Teilen, mit WhatsApp-Sharing per Fingertipp.

  • Freunde erhalten einen Rabatt – prozentual oder als fester Betrag, im Checkout wie jeder andere Gutschein eingelöst.
  • Empfehler werden belohnt – ein Gutschein wird automatisch ausgestellt, sobald die Bestellung des Freundes abgeschlossen ist und die Sperrfrist abgelaufen ist.
  • Codes statt Cookies – die Zuordnung läuft über den Gutschein in der Bestellung. Codes überstehen das Einfügen in WhatsApp, Instagram-DMs oder überall dort, wo Links verstümmelt werden. Empfehlungslinks (?ref=CODE) merken sich den Code einfach und wenden ihn automatisch an.
  • Rückerstattungssicher – Belohnungen werden für eine einstellbare Anzahl von Tagen zurückgehalten. Eine vollständige Erstattung oder Stornierung während dieser Frist storniert die Belohnung; Teilerstattungen lassen sie bestehen. Nach der Sperrfrist widerruft eine vollständig erstattete Bestellung den Belohnungs-Gutschein automatisch, sofern er noch nicht eingelöst wurde, und markiert die Empfehlung zur Prüfung, wenn er bereits eingelöst wurde.
  • Betrugsschutz – Eigenempfehlungen werden blockiert (per Konto und Rechnungs-E-Mail), jeder Freund kann pro Code auf eine Bestellung begrenzt werden, Codes lassen sich insgesamt begrenzen, und Sie können Codes auf Neukunden beschränken.
  • Kompatibel mit HPOS und Checkout Blocks.

Kein Auszahlungssystem, keine Steuerformulare, keine Freigabewarteschlangen – Belohnungen sind Shop-Gutscheine, so bleibt das Geld in Ihrem Shop.

Fragen

Wie schneidet es im Vergleich zu Alternativen ab?

Affiliate-Plattformen wie AffiliateWP, SliceWP und Solid Affiliate sind dafür gebaut, externe Marketer zu gewinnen, mit Registrierungsabläufen, Tracking-Dashboards und Auszahlungsläufen. Gehostete Dienste wie ReferralCandy betreiben Empfehlungsprogramme als Abo außerhalb von WordPress. Sawir Referral ist bewusst schlanker: Ihre bestehenden Kunden teilen einen persönlichen Gutscheincode oder Link, Freunde erhalten einen Rabatt, und Belohnungen sind Shop-Gutscheine. Die Zuordnung läuft über den Gutschein selbst, deshalb überlebt sie das Einfügen in Chat-Apps und braucht keine Auszahlungsinfrastruktur. Wenn Sie einen Affiliate-Kanal aufbauen, nutzen Sie eine Affiliate-Plattform; wenn Ihre Kunden Freunde empfehlen sollen, ist das die passende Lösung.

Wie wird eine Empfehlung zugeordnet?

Über den Gutschein in der Bestellung. Wurde beim Checkout ein Empfehlungscode verwendet, erhält der Empfehler, dem der Code gehört, die Gutschrift, sobald die Bestellung abgeschlossen ist. Empfehlungslinks speichern den Code lediglich in einem First-Party-Cookie und wenden ihn automatisch im Warenkorb an – es gibt kein separates Tracking-System.

Was passiert, wenn eine empfohlene Bestellung erstattet wird?

Teilerstattungen lassen die Belohnung bestehen – sie ist ein fester Betrag und hängt nicht vom Bestellwert ab. Eine vollständige Erstattung oder Stornierung während der Sperrfrist storniert die Belohnung, bevor sie ausgestellt wird. Wird die Bestellung nach der Ausstellung der Belohnung vollständig erstattet, wird der Belohnungs-Gutschein automatisch widerrufen (in den Papierkorb verschoben, im Gutschein-Bereich wiederherstellbar), solange er nicht eingelöst wurde; eine bereits eingelöste Belohnung wird in der Admin-Liste zur Prüfung markiert. Sie können jede Empfehlung außerdem manuell freigeben, rückgängig machen oder widerrufen unter WooCommerce → Referrals.

Können Kunden sich selbst empfehlen?

Nein. Codes werden abgelehnt, wenn der Kunde der Inhaber des Codes ist oder dieselbe E-Mail-Adresse wie der Inhaber hat, und die Prüfung wird beim Abschluss der Bestellung wiederholt.
