# Sawir Restock Notifier

![Banner von Sawir Restock Notifier](https://sawirstudio.com/assets/images/plugins/sawir-restock-notifier-for-woocommerce-banner.webp)

Mit Sawir Restock Notifier hinterlassen Kunden bei einem ausverkauften Produkt ihre E-Mail-Adresse und werden genau einmal benachrichtigt, sobald es wieder verfügbar ist.

[Kostenlos auf WordPress.org herunterladen](https://wordpress.org/plugins/sawir-restock-notifier-for-woocommerce/)

## Was es kann

Sawir Restock Notifier for WooCommerce ergänzt ausverkaufte Produktseiten um ein schlankes Formular für Verfügbarkeitsbenachrichtigungen. Kunden geben ihre E-Mail-Adresse ein, bestätigen die Anfrage per E-Mail und erhalten anschließend einmalig eine E-Mail, sobald das Produkt oder die ausgewählte Variante wieder auf Lager ist.

## Funktionen

- Zeigt ein Formular für Verfügbarkeitsbenachrichtigungen im Lagerhinweis ausverkaufter Produkte an.
- Unterstützt einfache Produkte und Produktvarianten.
- Funktioniert für Gäste und für angemeldete Kunden.
- Optionale Einstellung, die eine Anmeldung voraussetzt, bevor sich Kunden für Verfügbarkeitsbenachrichtigungen eintragen können.
- Nutzt eine Double-Opt-in-Bestätigung, bevor eine Benachrichtigung aktiviert wird.
- Enthält Links zum Stornieren und Abbestellen in den E-Mails an Kunden.
- Admins können Bestätigungs-E-Mails für unbestätigte Anfragen erneut senden.
- Ergänzt eine Seite „Mein Konto > Restock Alerts“, auf der angemeldete Kunden Benachrichtigungen, die sie im angemeldeten Zustand angelegt haben, ansehen, stornieren, abbestellen und deren Bestätigungs-E-Mail erneut anfordern können.
- Speichert Anfragen mit den Status „Bestätigung ausstehend“, „Bestätigt“, „Benachrichtigt“ und „Abbestellt“ in einer eigenen Datenbanktabelle.
- Versendet Restock-E-Mails im WooCommerce-Design, sobald der Lagerstatus wieder auf „Auf Lager“ wechselt.
- Verarbeitet den Versand der Benachrichtigungen in Hintergrund-Batches mit dem WooCommerce Action Scheduler.
- Ergänzt im Backend eine Seite „WooCommerce > Restock Alerts“ zur Prüfung der Anfragen.
- Zeigt ein Insights-Dashboard für Admins mit Zeitraumfiltern, Statussummen, Quoten und den am häufigsten angefragten Produkten.
- Optionale Einstellung zum Löschen der Plugin-Daten, wenn das Plugin entfernt wird.
- Fragt Admins beim Deaktivieren, ob die Plugin-Daten behalten oder unwiderruflich gelöscht werden sollen, falls das Plugin später entfernt wird.

## Fragen

### Wie schneidet es im Vergleich zu Alternativen ab?

Waitlist-Suiten wie YITH WooCommerce Waiting List und die kommerziellen Back-in-Stock-Erweiterungen bieten zusätzlich Dashboards, exportierbare Wartelisten, SMS und Marketing-Integrationen. Sawir Restock Notifier beschränkt sich auf das Wesentliche: ein kleines Formular bei ausverkauften Produkten, eine Double-Opt-in-Bestätigung und eine E-Mail, sobald das Produkt oder die Variante wieder verfügbar ist. Wenn Sie Ihre Warteliste für Marketing nutzen möchten, wählen Sie eine Suite. Wenn Sie aber einfach nicht wollen, dass Kunden bei einem ausverkauften Produkt abspringen, erfüllt dieses Plugin genau diesen Zweck.

### Setzt das WooCommerce voraus?

Ja. Dieses Plugin ist für WooCommerce-Produkte und Hooks des Lagerstatus entwickelt.

### Werden Kunden mehr als einmal benachrichtigt?

Nein. Jede Anfrage wird nach dem Versand einer Restock-E-Mail als benachrichtigt markiert.

### Wird Double Opt-in unterstützt?

Ja. Kunden müssen auf den Bestätigungslink klicken, bevor die Benachrichtigung aktiv wird.
