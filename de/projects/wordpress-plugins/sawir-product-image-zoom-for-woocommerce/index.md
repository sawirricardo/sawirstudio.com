# Sawir Product Image Zoom

![Banner von Sawir Product Image Zoom](https://sawirstudio.com/assets/images/plugins/sawir-product-image-zoom-for-woocommerce-banner.webp)

Sawir Product Image Zoom öffnet Ihre Produktfotos in einer Lightbox. Mit Pfeilen blättern Sie durch die Galerie, per Klick zoomen Sie in die Details.

[Kostenlos auf WordPress.org herunterladen](https://wordpress.org/plugins/sawir-product-image-zoom-for-woocommerce/)

## Was es kann

Sawir Product Image Zoom for WooCommerce ersetzt das Standardverhalten beim Klick auf ein Bild in der WooCommerce-Produktgalerie durch eine übersichtliche Lightbox.

Funktionen:

- Öffnet Produktbilder in einer Lightbox im Vollbildmodus.
- Bietet Navigation zum vorherigen und nächsten Bild.
- Unterstützt die Tastaturbedienung mit Escape, Pfeil nach links und Pfeil nach rechts.
- Unterstützt die Navigation per Wischgeste auf Touch-Geräten.
- Bietet Zoomen per Klick und Verschieben des Bildausschnitts per Ziehen, solange gezoomt ist.
- Funktioniert mit klassischen WooCommerce-Produktgalerien und mit blockbasierten Produktgalerien.

Das Plugin lädt sein CSS und JavaScript nur auf einzelnen Produktseiten.

## Fragen

### Wie schneidet es im Vergleich zu Alternativen ab?

Galerie-Suiten wie Iconic WooThumbs und YITH Zoom Magnifier ersetzen die gesamte WooCommerce-Produktgalerie: Layouts, Slider, Video und Zoom in einem. Sawir Product Image Zoom ändert nur eine Sache: was passiert, wenn Kunden auf ein Bild klicken. Die Galerie Ihres Themes bleibt unverändert, und Ihre Kunden erhalten eine schnelle Lightbox mit Tastaturbedienung, Wischgesten und Zoom per Klick. Die Dateien werden nur auf Produktseiten geladen. Wenn Sie die Galerie selbst umgestalten möchten, greifen Sie zu einer Suite. Wenn die Galerie in Ordnung ist und nur das Betrachten der Bilder besser werden soll, ist dies der schlankere Weg.

### Setzt das WooCommerce voraus?

Ja. Das Plugin ist für WooCommerce-Produktgalerien entwickelt.

### Werden die Dateien auf der gesamten Website geladen?

Nein. Die Dateien werden nur auf einzelnen WooCommerce-Produktseiten geladen.

### Unterstützt das Plugin Touch-Geräte?

Ja. Die Lightbox unterstützt die Navigation per Wischgeste und das Verschieben des gezoomten Bildausschnitts auf Touch-Geräten.
