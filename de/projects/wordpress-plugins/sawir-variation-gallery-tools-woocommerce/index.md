# Sawir Variation Gallery Tools

![Sawir Variation Gallery Tools Banner](https://sawirstudio.com/assets/images/plugins/sawir-variation-gallery-tools-woocommerce-banner.webp)

Sawir Variation Gallery Tools gibt jeder Produktvariante ihre eigene Galerie: Wählen Sie die rote Variante, sehen Sie Fotos der roten Variante. Das Plugin arbeitet Hand in Hand mit Sawir Product Image Zoom.

[Kostenlos auf WordPress.org herunterladen](https://wordpress.org/plugins/sawir-variation-gallery-tools-woocommerce/)

## Was es kann

Sawir Variation Gallery Tools für WooCommerce ergänzt im WooCommerce-Produkteditor bei jeder Variante das Feld „Zusätzliche Variantenbilder“.

Wählt ein Kunde auf der Produktseite eine Variante aus, werden die für diese Variante gespeicherten Bilder zur WooCommerce-Produktgalerie hinzugefügt.

Shop-Betreiber können zusätzliche Variantenbilder außerdem unter WooCommerce > Variation Images gesammelt exportieren und importieren. Der CSV-Export enthält pro Variante die ID, die Artikelnummer (SKU), die Attribute, die IDs der zusätzlichen Bilder und die Bild-URLs. Beim CSV-Import können die Bilder der importierten Zeilen ersetzt oder ergänzt werden.

Dieses Plugin funktioniert mit Sawir Product Image Zoom für WooCommerce: https://wordpress.org/plugins/sawir-product-image-zoom-for-woocommerce/

Die Variantenbilder werden als normale WooCommerce-Galeriebilder hinzugefügt. Deshalb kann Sawir Product Image Zoom für WooCommerce sie in seine Lightbox und Zoom-Funktion einbinden.

## Fragen

### Wie schneidet es im Vergleich zu Alternativen ab?

Plugins wie Additional Variation Images Gallery und Iconic WooThumbs verbinden Variantenbilder mit einem eigenen Galerie-Player – mit Slidern, Layouts und Video. Sawir Variation Gallery Tools speichert die Bilder pro Variante und übergibt sie an die Standard-Galerie von WooCommerce. So funktionieren Ihr Theme und ergänzende Plugins (etwa Sawir Product Image Zoom) unverändert weiter, und Shop-Betreiber können Bilder per CSV-Export und -Import gesammelt bearbeiten. Wenn Sie ein neues Galerieerlebnis möchten, greifen Sie zu einer Komplettlösung. Wenn Sie Variantenbilder in der Galerie nutzen wollen, die Sie bereits haben, ist dies die schlanke Lösung.

### Funktioniert das mit Sawir Product Image Zoom für WooCommerce?

Ja. Variantenbilder, die mit diesem Plugin hinzugefügt werden, nutzen das Standard-Markup der WooCommerce-Produktgalerie und funktionieren daher mit Sawir Product Image Zoom für WooCommerce.

### Kann ich Variantenbilder gesammelt aktualisieren, exportieren oder importieren?

Ja. Gehen Sie zu WooCommerce > Variation Images, um eine CSV-Datei zu exportieren oder zu importieren, die Varianten über `variation_id` oder `variation_sku` zuordnet. Die Importzeilen können vorhandene Anhangs-IDs aus der Mediathek oder URLs verwenden.
