# Sawir Role Capabilities Manager

![Banner von Sawir Role Capabilities Manager](https://sawirstudio.com/assets/images/plugins/sawir-role-capabilities-manager-banner.webp)

Mit Sawir Role Capabilities Manager legen Sie eigene Benutzerrollen an und bestimmen genau, was jede Rolle darf, egal ob neu erstellt oder bereits integriert.

[Kostenlos auf WordPress.org herunterladen](https://wordpress.org/plugins/sawir-role-capabilities-manager/)

## Was es kann

Sawir Role Capabilities Manager ergänzt unter „Benutzer“ eine Seite zur Verwaltung von Rollenrechten, die nur Administratoren sehen. Administratoren können Rollen erstellen, Berechtigungen aus bestehenden Rollen kopieren, eigene Capability-Schlüssel hinzufügen und die Berechtigungen vorhandener Rollen verwalten.

## Fragen

### Wie schneidet es im Vergleich zu Alternativen ab?

User Role Editor, Members und PublishPress Capabilities sind hier die etablierten Werkzeuge, deren Pro-Versionen zusätzlich Inhaltsbeschränkungen, Schutz im Frontend und Kontrolle über das Admin-Menü bieten. Sawir Role Capabilities Manager deckt die zentrale Verwaltungsaufgabe kostenlos auf einer einzigen Seite unter „Benutzer“ ab: Rollen erstellen, Berechtigungen zwischen Rollen kopieren, eigene Capability-Schlüssel hinzufügen und bestehende Rollen bearbeiten. Wenn Sie Inhalte beschränken oder Mitgliedschaftsstufen aufbauen möchten, greifen Sie zu Members oder PublishPress. Wenn Sie Rollen und Berechtigungen übersichtlich verwalten möchten, genügt dieses Plugin.
