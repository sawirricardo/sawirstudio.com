# Colvaron Conquest 網站

![Colvaron Conquest 首頁](https://sawirstudio.com/assets/images/projects/colvaron-conquest-website.webp)

## 客戶

Colvaron Conquest 是由 Coco JM 創作的策略型集換式卡牌遊戲。遊戲世界觀融合魔法與尖端科技，源自 Coco 童年時的想像，並在 2025 年化為卡牌遊戲，以五大元素與雙骰行動系統進行對戰。

## 我們的作品

我們設計並打造了這款遊戲的官方網站，讓玩家在這裡探索卡牌、認識世界觀，並學會如何遊玩。

- **卡牌圖鑑。** 超過 200 張卡牌，玩家可依元素、陣營與類型搜尋、排序及篩選。
- **每張卡牌都有專屬頁面，** 方便單獨查找、連結與分享。
- **世界觀故事。** 十五則 Colvaron 的故事：五大元素如何誕生、大陸的樣貌，以及各個王國與陣營。
- **教學。** 附有元素相剋表的遊玩規則，專為第一次接觸這款遊戲的玩家而設。
- **最新消息。** 團隊隨著遊戲成長所發布的各項更新。
- **簡單好用的 CMS。** 團隊可自行發布世界觀故事與最新消息，每次修改都會記錄在網站的 Git 歷史中。

## 我們的做法

集換式卡牌遊戲靠的是卡面美術，所以網站盡量不搶戲：深色頁面、大尺寸卡面圖片，以及能即時回應的篩選功能。在幕後，網站也針對搜尋做了最佳化。標題與描述鎖定卡牌玩家會搜尋的詞彙，每個頁面都列入完整的網站地圖；由於 Facebook、X 和 WhatsApp 無法顯示網站使用的 AVIF 圖片，建置時也會為每個頁面產生一張 JPEG 分享圖片。

**使用技術** Astro、Tailwind CSS 與 Cloudflare Pages
