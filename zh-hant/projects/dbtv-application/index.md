# DBTV 應用程式

Ps. Debby Basjir 的講道、禱告與每日靈修

![DBTV 應用程式橫幅](https://sawirstudio.com/assets/images/projects/dbtv-application.webp)

## 客戶

DBTV 是 Ps. Debby Basjir 事工的媒體頻道，為線上追隨的會眾提供講道、禱告聚會、敬拜與靈修內容。

## 我們的作品

我們為 DBTV 開發了 iOS 與 Android 版應用程式，讓會眾用手機就能隨時參與事工。

- **講道與敬拜。** 獨家講道影片、讚美敬拜與 Podcast，影片可直接在應用程式內播放。
- **禱告。** 線上禱告聚會，包含兒童專屬的 Mezbah Doa。
- **每日靈修。** 每天更新靈修內容，文字排版清晰好讀。
- **活動。** 瀏覽即將舉行的活動、線上報名，並查看您所報名的所有人。
- **商店。** DBTV 周邊商品，連結至其 Tokopedia 與 Shopee 商店。
- **DBTV+。** 會員方案，可搶先收看獨家內容。
- **通知。** 有新內容發布時，立即推送通知。

## 我們的做法

事工每天都有新內容，所以應用程式不把任何內容寫死：靈修、講道與活動都來自 DBTV 的平台，無需更新應用程式就會自動顯示。當應用程式本身有變動時，會提示使用者更新，讓所有會眾都使用同一個版本，不會有人被舊版的錯誤困擾。

**使用技術** Expo (React Native)
