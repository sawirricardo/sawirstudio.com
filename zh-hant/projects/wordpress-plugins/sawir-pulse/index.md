# Sawir Pulse

![Sawir Pulse 橫幅圖](https://sawirstudio.com/assets/images/plugins/sawir-pulse-banner.webp)

Sawir Pulse 會以角落的小型通知，讓購物者看到您商店裡真正發生的事，例如最新訂單、正在瀏覽商品的人數，以及最新評價。所有內容都不會造假。

[到 WordPress.org 免費取得](https://wordpress.org/plugins/sawir-pulse/)

## 功能介紹

Sawir Pulse 會以角落小型通知的方式，讓訪客看到您商店裡真實發生的事：

- **最新訂單**：「來自 Jakarta 的 Rina 購買了 Batik Tote · 12 分鐘前 · 已驗證訂單」
- **即時瀏覽人數**：「目前有 4 人正在瀏覽這項商品」
- **評價**：摘錄自已核准的 4 至 5 星商品評價

每一則通知都來自真實的活動。外掛沒有任何可以捏造購買紀錄或灌水數字的選項：虛假的社群證明會誤導購物者，對店家來說也有法律風險，所以 Sawir Pulse 一律不做這種事。全新的商店從第一天起就能顯示即時瀏覽人數與評價動態，購買通知則會在真實訂單進來後陸續出現。

### 功能特色

- 真實訂單、即時瀏覽人數、評價摘錄，可自由搭配組合
- 商品頁面內嵌「本週已售出 12 件」標章（僅在商品一週內確實售出 3 件以上時才會顯示）
- 在設定頁面中直接查看本月通知的顯示次數與點擊次數
- 隱私優先：只顯示名字與城市，並可一鍵匿名化（「來自 Jakarta 的某位顧客」）
- 預設在購物車與結帳頁面隱藏，讓購買過程不受干擾
- 訪客可以在本次瀏覽期間關閉通知
- 輕量化：僅一個小型樣式表與一個小型腳本，不使用外部服務，也不依賴 jQuery
- 尊重減少動態效果的偏好設定，對螢幕閱讀器友善
- 可透過 CSS 自訂屬性調整外觀主題
- 相容 HPOS

## 常見問題

### 與其他方案相比如何？

大多數社群證明工具，例如 TrustPulse、NotificationX、Fomo，可設定的項目更多，其中有些還能讓您手動編寫通知，或以雲端託管服務的方式運作。Sawir Pulse 的立場則更嚴格：每一則通知都來自真實訂單、真實訪客或真實評價，沒有任何捏造活動的選項，而且全部在您自己的網站上運作，不依賴外部服務。如果您需要跨平台的行銷活動或複雜的目標對象規則，託管式平台會更適合；如果您希望擁有可以向顧客和主管機關交代的社群證明，這項限制正是我們產品的價值所在。

### 我可以建立自訂或虛假的通知嗎？

不行，而且這是刻意的設計。捏造的社群證明會誤導購物者，也可能違反消費者保護法規。Sawir Pulse 只會顯示真實訂單、真實訪客與真實評價。

### 會顯示哪些顧客資料？

最多只會顯示帳單地址中的名字與城市，以及所購買的商品。啟用「隱藏顧客姓名」後，就會改為顯示「來自 Jakarta 的某位顧客」。瀏覽人數是以短期有效的加鹽雜湊值計算，不會儲存 IP 位址或任何個人資料。

### 我的商店剛開張，還沒有任何訂單，訪客會看到什麼？

如果已有即時瀏覽人數與評價摘錄，就會顯示這些內容。等到出現真實訂單，購買通知會自動出現。如果目前還沒有任何真實活動，就什麼都不會顯示，這樣才是正確的做法。
