Sawir Media Folders

Sawir Media Folders 為 WordPress 媒體庫加入資料夾功能，數量不限，還能用拖放方式整理檔案。

到 WordPress.org 免費取得

功能介紹

將您的媒體庫整理成資料夾與子資料夾。沒有資料夾數量限制，也沒有付費誘導。

  • 資料夾與子資料夾數量不限：沒有上限。
  • 速度快：無論媒體庫有多大，整個資料夾樹狀結構只需兩次資料庫查詢即可載入。篩選則使用 WordPress 原生的媒體查詢。
  • 安全：資料夾是虛擬的（以分類法 taxonomy 實作），實體檔案完全不會移動，因此不會有任何網址失效。刪除資料夾也不會刪除檔案。

常見問題

與其他方案相比如何？

FileBird、HappyFiles 和 Real Media Library 都是成熟的資料夾外掛，功能完善、附加功能也很精緻，但它們的免費版通常會限制可建立的資料夾數量。Sawir Media Folders 則把範圍收斂在虛擬資料夾、拖放操作和快速篩選上，沒有數量限制，也沒有付費方案。資料夾是以分類法（taxonomy）實作，所以檔案不會真的被移動，也不會有網址失效。如果您需要像是個別使用者資料夾或圖庫整合這類額外功能，付費方案確實物有所值；如果您只是想把媒體庫整理好，這個外掛免費又快速。

資料夾會改變我的檔案網址嗎？

不會。資料夾純粹用於整理（以隱藏的分類法套用在附件上），檔案會維持在 WordPress 上傳時的原始位置。

如果我停用或刪除這個外掛，會怎麼樣？

不會有任何損壞。您的檔案不會受到影響，資料夾的歸類只是不再顯示。重新啟用後，一切就會恢復。

免費版有資料夾數量限制嗎？

這個外掛沒有付費版，所有功能都免費且不限量。
