Sawir Variation Gallery Tools

Sawir Variation Gallery Tools 讓每個商品款式都有專屬的圖片集，選擇紅色款式時，就會顯示紅色款式的照片。它可與 Sawir Product Image Zoom 搭配使用。

在 WordPress.org 免費取得

功能介紹

Sawir Variation Gallery Tools for WooCommerce 會在 WooCommerce 商品編輯器的每個商品款式中，新增「Additional variation images」欄位。

當顧客在商品頁面選擇某個款式時，該款式已儲存的圖片就會加入 WooCommerce 的商品圖片集。

商店管理員也可以在 WooCommerce > Variation Images 批次匯出與匯入額外的款式圖片。CSV 匯出檔包含每個款式的 ID、SKU、屬性、額外圖片 ID 以及圖片網址。CSV 匯入時，可以取代或附加至匯入列的既有圖片。

此外掛可搭配 Sawir Product Image Zoom for WooCommerce 使用：https://wordpress.org/plugins/sawir-product-image-zoom-for-woocommerce/

款式圖片會以標準的 WooCommerce 圖片集圖片形式加入，因此 Sawir Product Image Zoom for WooCommerce 可以將它們納入燈箱與縮放瀏覽體驗中。

常見問題

與其他方案相比如何？

Additional Variation Images Gallery 與 Iconic WooThumbs 等外掛，會將各款式圖片搭配自家的圖片集播放器，包含滑動輪播、版面配置與影片。Sawir Variation Gallery Tools 則是儲存各款式的圖片，並交給標準的 WooCommerce 圖片集使用，因此您的佈景主題與搭配的外掛（例如 Sawir Product Image Zoom）都能照常運作，商店管理員也能透過 CSV 匯出與匯入進行批次編輯。如果您想要全新的圖片集體驗，請選擇完整套件；如果您想把款式圖片放進現有的圖片集裡，這個外掛就是專注於此的選擇。

這個外掛可以搭配 Sawir Product Image Zoom for WooCommerce 使用嗎？

可以。此外掛新增的款式圖片使用標準的 WooCommerce 商品圖片集標記，因此可與 Sawir Product Image Zoom for WooCommerce 搭配運作。

我可以批次更新、匯出或匯入款式圖片嗎？

可以。前往 WooCommerce > Variation Images，即可匯出 CSV，或匯入以 variation_id 或 variation_sku 比對款式的 CSV。匯入列可以使用媒體庫中既有的附件 ID 或網址。

推薦搭配

  • Sawir Product Image Zoom：以燈箱開啟您的商品照片，可用箭頭切換圖片集，點擊即可放大查看細節。
  • Sawir Restock Notifier：讓顧客在缺貨商品上留下電子郵件，商品補貨時只通知他們一次。
