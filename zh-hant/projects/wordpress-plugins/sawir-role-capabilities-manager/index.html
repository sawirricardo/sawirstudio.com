Sawir Role Capabilities Manager

Sawir Role Capabilities Manager 讓您建立自訂的使用者角色，並精確決定每個角色（無論是新建的還是內建的）可以執行哪些操作。

到 WordPress.org 免費下載

功能介紹

Sawir Role Capabilities Manager 會在「使用者」選單下新增一個僅限管理員使用的角色權限頁面。管理員可以建立角色、從現有角色複製權限、新增自訂權限鍵，也能管理現有角色的權限。

常見問題

與其他方案相比如何？

User Role Editor、Members 和 PublishPress Capabilities 是這類外掛中較為成熟的工具，其付費版本還提供內容限制、前台保護和後台選單控制等功能。Sawir Role Capabilities Manager 則把核心的管理工作集中在「使用者」下的同一個畫面，而且免費：建立角色、在角色之間複製權限、新增自訂權限鍵，以及編輯現有角色。如果您需要限制內容或建立會員等級，請選擇 Members 或 PublishPress；如果您只需要簡潔的角色與權限管理，用這個就夠了。

推薦搭配

  • Sawir Media Folders：為 WordPress 媒體庫加入資料夾功能，數量不限，並可透過拖放來整理檔案。
  • Sawir Live Translate：直接在原頁面上翻譯您的內容：選擇語言、自動翻譯畫面上看得到的文字、儲存，並為訪客提供語言切換器。
