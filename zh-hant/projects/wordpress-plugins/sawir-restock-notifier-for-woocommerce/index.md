# Sawir Restock Notifier

![Sawir Restock Notifier 橫幅圖](https://sawirstudio.com/assets/images/plugins/sawir-restock-notifier-for-woocommerce-banner.webp)

Sawir Restock Notifier 讓顧客在缺貨商品頁留下電子郵件，並在商品重新到貨時通知他們一次。

[到 WordPress.org 免費取得](https://wordpress.org/plugins/sawir-restock-notifier-for-woocommerce/)

## 功能介紹

Sawir Restock Notifier for WooCommerce 會在缺貨的商品頁加上輕量的到貨通知表單。顧客輸入電子郵件地址，透過郵件確認申請後，當商品或所選規格重新有貨時，就會收到一封一次性的通知郵件。

## 功能特色

- 在缺貨商品的庫存提示中顯示到貨通知表單。
- 支援單一商品與商品變化規格。
- 支援訪客與已登入的顧客。
- 可選擇是否要求顧客先登入，才能訂閱到貨通知。
- 採用雙重確認（double opt-in）機制，確認後才會啟用到貨通知。
- 寄給顧客的郵件中附有取消與退訂連結。
- 管理員可以針對尚未確認的申請重新寄送驗證郵件。
- 新增「我的帳號 > 到貨通知」頁面，已登入的顧客可以查看、取消、退訂，並針對登入時建立的通知重新寄送驗證郵件。
- 將待確認、已確認、已通知與已退訂的申請儲存在自訂的資料庫資料表中。
- 當庫存狀態變回有貨時，寄出符合 WooCommerce 樣式的到貨通知郵件。
- 透過 WooCommerce Action Scheduler 以背景批次方式處理到貨通知郵件。
- 新增「WooCommerce > 到貨通知」管理頁面，方便檢視各項申請。
- 提供管理員數據分析儀表板，包含日期範圍篩選、各狀態總數、比率，以及最多人申請的商品。
- 提供選用的解除安裝清理設定，可在刪除外掛時一併移除外掛資料。
- 停用外掛時，會詢問管理員日後若刪除外掛，要保留外掛資料還是徹底移除。

## 常見問題

### 與其他方案相比如何？

像 YITH WooCommerce Waiting List 這類候補名單套件，以及付費的到貨通知擴充功能，會提供儀表板、可匯出的候補名單、簡訊與行銷整合。Sawir Restock Notifier 只專注於最核心的流程：在缺貨商品頁放一個小表單、雙重確認，以及商品或規格重新到貨時寄出一封郵件。如果您打算對候補名單做行銷，請選擇功能完整的套件；如果您只是不想讓顧客在缺貨頁面直接離開，這個外掛正好能做到。

### 這個外掛需要 WooCommerce 嗎？

可以。這個外掛是專為 WooCommerce 商品與庫存狀態掛鉤（hook）所打造。

### 會重複通知顧客嗎？

不會。每筆申請在到貨通知郵件寄出後，就會標記為已通知。

### 支援雙重確認嗎？

支援。顧客必須點擊確認連結，到貨通知才會生效。
