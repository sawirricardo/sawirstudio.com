Sawir Referral

Sawir Referral 讓您的顧客帶朋友來消費。朋友享有折扣，分享的顧客則獲得回饋優惠券，而且可以透過代碼、連結，或直接用 WhatsApp 分享。

功能介紹

讓您的顧客成為您的銷售管道。每位顧客都會在「我的帳號」頁面取得專屬推薦碼（就是一組真正的 WooCommerce 優惠券）和分享連結，並可一鍵透過 WhatsApp 分享。

  • 朋友享有折扣：可設定為百分比或固定金額，結帳時像一般優惠券一樣套用。
  • 推薦人獲得回饋：朋友的訂單完成且保留期結束後，系統會自動發放一張優惠券。
  • 靠代碼，不靠 Cookie：歸屬判定是透過訂單上的優惠券。代碼貼到 WhatsApp、Instagram 私訊，或任何連結容易被改動的地方，依然有效。分享連結（?ref=CODE）則會記住代碼並自動套用。
  • 退款無虞：回饋會依設定的天數保留。保留期間若發生全額退款或訂單取消，回饋會一併取消；部分退款則仍保留回饋。保留期結束後，若訂單全額退款，且回饋優惠券尚未使用，系統會自動撤銷；若已被使用，則會將該筆推薦標記出來供您審核。
  • 防濫用機制：禁止自我推薦（依帳號與帳單電子郵件判斷），每位朋友可限制每組代碼只能下一筆訂單，代碼可設定使用總次數上限，也可以限定只有新顧客才能使用。
  • 相容 HPOS 與結帳區塊（Checkout Blocks）。

沒有撥款系統、沒有稅務表單、沒有審核佇列：回饋就是商店優惠券，錢也就留在您的商店裡。

常見問題

與其他方案相比如何？

聯盟行銷平台（如 AffiliateWP、SliceWP、Solid Affiliate）是為了招募外部行銷人員而設計，包含註冊流程、追蹤儀表板和撥款作業。ReferralCandy 這類代管服務，則是以訂閱方式在 WordPress 之外執行推薦計畫。Sawir Referral 刻意定位得更單純：由您現有的顧客分享專屬優惠券代碼或連結，朋友享有折扣，回饋則是商店優惠券。歸屬判定直接透過優惠券，所以貼到聊天軟體也不會失效，也不需要任何撥款機制。如果您想建立聯盟行銷管道，請使用聯盟行銷平台；如果您希望讓顧客推薦朋友，這就是最合適的做法。

推薦是如何歸屬的？

透過訂單上的優惠券。如果結帳時使用了推薦碼，訂單完成後，擁有該代碼的推薦人就會獲得這筆推薦。分享連結只是把代碼存入第一方 Cookie，並自動套用到購物車，並沒有另外的追蹤系統。

被推薦的訂單退款時會怎麼處理？

部分退款仍會保留回饋，因為回饋是固定金額，不會隨訂單金額增減。保留期間若發生全額退款或訂單取消，回饋會在發放前就被取消。如果回饋發放後訂單才全額退款，只要回饋優惠券尚未使用，系統就會自動撤銷（移至垃圾桶，可從優惠券頁面還原）；若回饋已被使用，則會在後台列表中標記，讓您自行審核。您也可以隨時從 WooCommerce → Referrals 手動釋出、回沖或撤銷任何一筆推薦。

顧客可以推薦自己嗎？

不行。若顧客就是代碼的擁有者，或與擁有者使用相同的電子郵件，該代碼會被拒絕，訂單完成時也會再檢查一次。

推薦搭配

  • Sawir Renew：把 WooCommerce 商店變成訂閱制事業：定期扣款、試用期、註冊費和智慧重試，沒有任何功能被鎖在付費方案之後。
  • Sawir Pulse：以角落的小通知，讓購物者看到您商店裡實際發生的事，例如最新訂單、正在瀏覽商品的人數和最新評價。
