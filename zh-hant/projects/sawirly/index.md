# Sawirly

注重隱私的短網址服務，不追蹤使用者，連結還能設定到期

多數短網址服務會追蹤您的點擊、顯示廣告，或蒐集個人資料。Sawirly 不會：我們不會記錄或辨識您的 IP 位址、所在位置或瀏覽器，每個連結預設都是乾淨且私密的。

連結可以自訂別名、設定起訖日期，也可以設為只能點擊一次。Sawirly 供個人免費使用，開發人員則能使用簡潔、尊重隱私的 API。
