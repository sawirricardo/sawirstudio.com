# Pawlitics

一款溫馨卡通風的政治模擬遊戲，小鎮裡的動物會對每項政策做出反應

Bramblewood 需要一位州長，會是您嗎？

Pawlitics 是一款溫馨的卡通政治模擬遊戲。選出一位州長、制定政策，然後看著滿城的動物們有什麼反應：戴著安全帽的熊、打著領結的雞，還有住在鞋盒裡、而且說其實住起來還不錯的老鼠。
