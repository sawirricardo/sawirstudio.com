# Squishu

壓扁包子，在蒸氣散盡前打敗魔王。

Squishu 是一款可愛的點擊遊戲，主題是壓扁各種食物。點一點餃子、飯糰、壽司、麻糬、珍珠奶茶等等，直到它們啵地爆開，再在計時結束前挑戰每個世界的魔王。您還可以雇用一群餃子夥伴，在您離開時繼續幫您壓扁食物，回來時就能看到蒸籠裡裝滿了金幣。
