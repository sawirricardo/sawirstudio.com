新服務：Shopify

# 帳目對得上 的 Shopify。

訂單、庫存、撥款與 POS 門市銷售，在您的 Shopify 商店與 Odoo 或其他系統之間順暢流通。由開發開源 Shopify Odoo 連接器的團隊親手打造，讓帳目分毫不差。

[開始專案](https://sawirstudio.com/zh-hant/contact/) [了解連接器](https://sawirstudio.com/zh-hant/projects/odoo-shopify-connector/)

## 我們的服務

- ### Shopify 與 Odoo

  透過我們開發的 [OCA 連接器](https://sawirstudio.com/zh-hant/projects/odoo-shopify-connector/)，將您的商店與 Odoo 19 Community 串接：商品、庫存、客戶、訂單、退貨與退款，單一或多間商店都適用。我們負責安裝、依您的作業方式設定，並在您的環境需要時擴充功能。還沒使用 Odoo？我們也能[協助導入](https://sawirstudio.com/zh-hant/odoo/)。
- ### 帳目對得上

  Shopify Payments 的撥款、手續費、爭議款項、禮物卡與多幣別，都依 Shopify 的精確金額產生日記帳分錄。若有對不上的地方，您會看到明確的錯誤訊息，而不是被悄悄補平的差額。
- ### POS 門市與倉庫

  各門市的 Shopify POS 銷售會以訂單匯入，並分派到正確的 Odoo 倉庫，讓您所有銷售通路的庫存都正確無誤。
- ### 您的其他系統

  沒有使用 Odoo？我們也能透過 GraphQL Admin API 與簽章 Webhook，把 Shopify 連接到您現有的 ERP、會計、物流或自訂後端系統，並設有檢查機制，抓出任何遺漏。
- ### 客製應用程式與自動化

  針對 Shopify 預設功能無法處理的需求，我們可以開發私有應用程式或排程作業：訂單分派、批次編輯、自訂報表、與供應商同步資料。
- ### 商店本身也能做

  如果您的前台需要建置或改版，我們可以和整合一併設計與開發，讓前台與後台一起規劃。

## 運作方式

1. ### 先畫出流程。

   我們會列出每一條資料流：哪些資料要傳送、傳送方向為何，以及庫存、價格與金額以哪個系統為準。
2. ### 一次處理一條流程。

   通常先處理訂單與庫存，再來是會計，最後是 POS。每一項都先用您的真實資料驗證，再進行下一項。
3. ### 長期穩定運作。

   健康檢查、同步儀表板與定期對帳，再加上我們。Shopify 調整 API 時，我們也會持續維護。

我們不會做的事

只在大多數時候正確的整合。對庫存和金額來說，這就是錯誤。我們做的整合不會假設 Webhook 一定送達，會定期與 Shopify 自我核對，並在數字對不上時停下來通知您。
