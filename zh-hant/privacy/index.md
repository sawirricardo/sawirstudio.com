# 本網站蒐集 哪些資料

直接說明：我們量測什麼、您提供給我們什麼，以及還有哪些服務會處理這些資料。

*最後更新日期：2026 年 11 月 27 日*

## 我們如何量測網站使用情況

我們使用 [Microsoft Clarity](https://clarity.microsoft.com/) 了解大家如何使用本網站：開啟了哪些頁面、點擊了哪裡、捲動到多深的位置。Clarity 也會將瀏覽過程錄製成重播，並記錄您的瀏覽器、裝置、大概的所在位置，以及帶您來到本站的來源頁面。它可能會設定 Cookie，以區分不同次的造訪。

我們查看這些資料，是為了找出令人困惑或有問題的地方並加以修正。我們不會販售這些資料。Microsoft 依據 [Microsoft 隱私權聲明](https://privacy.microsoft.com/privacystatement)處理這些資料。

## 當您與我們聯絡時

[聯絡表單](https://sawirstudio.com/zh-hant/contact/)會將您的姓名、電子郵件、公司名稱（如有填寫）、需求項目和訊息內容傳送到我們自己的伺服器。伺服器會將這些資料連同您的 IP 位址和瀏覽器資訊存入我們的資料庫，並透過 Cloudflare 以電子郵件寄給我們。我們會用這些資料回覆您，並與您討論您的專案。您只要提出要求，我們就會刪除資料。

## 當您訂閱部落格時

每篇部落格文章末尾的訂閱表單，會將您的電子郵件地址存入我們自己的資料庫，同時記錄您訂閱時所在的頁面、您的 IP 位址和瀏覽器資訊。我們會透過 Cloudflare 寄一封信給您確認電子郵件地址，之後每有新文章就寄一封通知。每封信都附有取消訂閱的連結，取消後我們就不會再寄任何信件給您。您只要提出要求，我們也會刪除您的電子郵件地址。

## 本網站載入的服務

字型來自 Google Fonts，因此當您的瀏覽器擷取字型時，會將您的 IP 位址提供給 Google（[Google 隱私權政策](https://policies.google.com/privacy)）。本網站託管於 Cloudflare，您的每一個請求在送達您手上的途中都會經過 Cloudflare 處理（[Cloudflare 隱私權政策](https://www.cloudflare.com/privacypolicy/)）。

## 儲存在您瀏覽器中的資料

如果您切換淺色或深色模式，瀏覽器會將您的選擇記在本機儲存空間中。這項資料只會留在您的裝置上，不會傳送給我們。

## 我們的應用程式

我們的每個應用程式都有各自的隱私權政策，可從其 App Store 頁面連結查看。您可以在[專案](https://sawirstudio.com/zh-hant/projects/)中看到全部應用程式。

## 常見問題

若您對自己的資料有疑問，或想要刪除資料，請透過[聯絡表單](https://sawirstudio.com/zh-hant/contact/)與我們聯繫。
