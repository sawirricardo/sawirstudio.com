新服務：Odoo 與商業系統

從收銀台到帳務，一套系統搞定。

POS 銷售、庫存、採購與會計整合在同一處。如果 Odoo 適合您的作業方式，就用 Odoo；不適合，就量身打造。在您花任何一毛錢之前，我們會先告訴您該選哪一種。

開始專案 Odoo 還是客製化？

我們的服務

  • 為您建置 Odoo

    POS 銷售、庫存、採購、銷售與會計，都依照您現有的營運方式來設定，而不是讓您去配合系統。我們會為 Odoo 撰寫模組，所以對它的內部運作瞭若指掌。

  • 所有門市，庫存一次掌握

    每個門市與倉庫共用同一份庫存，支援尺寸與顏色等商品規格、條碼、門市間調撥，還有在缺貨前就會提醒您的補貨點。

  • 線上銷售與實體共用同一份庫存

    透過我們開發的開源連接器串接您的 Shopify 商店，您的網站或其他通路則透過 API 串接，讓您不會賣出已經沒有的商品。

  • 量身打造

    當您的作業方式正是您與眾不同之處，我們就圍繞它來打造系統：給辦公室使用的網頁應用程式、給員工或顧客使用的 App，以及背後的管理後台。程式碼與資料都歸您所有。請參考客製化軟體。

  • Odoo 加上您專屬的功能

    很多時候，Odoo 已涵蓋幾乎所有需求，只有其中一個環節需要專屬的做法。我們會以 Odoo 為核心，另外開發它所沒有的那個模組、App 或報表。

  • 資料導入

    將商品、客戶、供應商、期初庫存與餘額，從試算表或舊系統匯入，並在上線前訓練好第一線的櫃檯人員。

Odoo 還是客製化？

這是大家最先會問的問題，而老實的答案，取決於您的業務究竟有多特殊。

  • 選 Odoo：您的流程就是一般商店、經銷商與餐廳的做法：銷售、補貨、付款給供應商、月底結帳。這樣做更快、更便宜，而且是開源的，Odoo Community 不需要授權費用。您只需要稍微調整做法來配合它。
  • 選量身打造：系統本身就是您的事業，例如定價模式、核准流程，或是 Odoo 每一步都會卡關的服務。前期成本較高，但能完全貼合您的需求。
  • 兩者並用：Odoo 負責日常作業，而您的業務中有一個環節是獨一無二的。這是最常見的答案。

我們會先釐清您的流程，再以書面方式建議其中一種，並附上各自的費用。無論您選哪一種，都是建立在開放、主流的工具上，任何優秀的開發人員都能接手，所以您不會被我們綁住。

運作方式

  1. 先實地走一遍。

    我們會照著目前實際的運作方式，跟著一筆銷售、一次出貨、一次盤點和一次月結走一遍，並記下哪些環節會出差錯。

  2. 一次處理一個部分。

    通常先處理收銀與庫存，接著是採購，最後是會計。每個部分都先用您的真實資料運作順暢，再進行下一步，所以店面不會停擺。

  3. 我們會持續陪伴。

    新增門市、新報表、Odoo 版本升級，以及忙碌的週六冒出來的各種問題。PeopleBond 從 2019 年起就一直與我們合作。

我們不會做的事

賣給您不需要的系統。如果 Odoo 的標準應用程式就能滿足需求，我們會直接告訴您，不加客製化開發。如果您的流程真的不一樣，我們也不會只因為對我們比較省事，就硬把它塞進 Odoo。

Ricardo Sawir，創辦人
