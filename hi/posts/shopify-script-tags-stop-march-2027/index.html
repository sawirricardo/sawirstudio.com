  3. 1 मार्च 2027 से Shopify Script Tags काम करना बंद कर देंगे। स्टोर ओनर्स को क्या करना चाहिए

1 मार्च 2027 से Shopify Script Tags काम करना बंद कर देंगे। स्टोर ओनर्स को क्या करना चाहिए

1 मार्च 2027 से Shopify ऑनलाइन स्टोरफ़्रंट में script tags लोड करना बंद कर देगा। आपके स्टोर पर जो कुछ भी अब भी इस तरीके से लोड होता है, जैसे रिव्यू विजेट, चैट बबल या ट्रैकिंग पिक्सल, वह बस दिखना बंद हो जाएगा। कोई एरर नहीं आएगा। चीज़ें चुपचाप गायब हो जाएँगी।

Shopify ने इसकी घोषणा अगस्त 2026 में की थी। अगर आप कोई स्टोर चलाते हैं, तो इसका आपके लिए क्या मतलब है, यह यहाँ समझिए।

Script tag क्या होता है

Script tag एक ऐसा तरीका है जिससे कोई ऐप API के ज़रिए आपके स्टोरफ़्रंट में JavaScript जोड़ सकता है, वह भी आपकी थीम को छुए बिना। ऐप डेवलपर्स को यही तरीका पसंद था, और यही इसकी समस्या भी है: script tags थीम एडिटर में दिखाई नहीं देते, इसलिए आप वहाँ से न उन्हें देख सकते हैं, न बंद कर सकते हैं। अनइंस्टॉल किए गए ऐप कभी-कभी अपने script tags पीछे छोड़ जाते हैं।

समय-सीमा

  • 1 अक्टूबर 2026: ऐप अब किसी भी API वर्शन पर script tags बना या अपडेट नहीं कर सकेंगे। पहले से मौजूद script tags चलते रहेंगे।
  • 1 मार्च 2027: Shopify ऑनलाइन स्टोर के script tags लोड करना बंद कर देगा।

ऑर्डर स्टेटस पेज पर script tags पहले ही अलग समय-सारणी के तहत बंद किए जा चुके हैं। इसलिए अगर वहाँ कुछ पहले से दिखना बंद हो गया है, तो यही कारण है।

अपना स्टोर कैसे जाँचें

Shopify merchants को script tags की कोई सूची नहीं देता, इसलिए आपको खुद देखना होगा:

  1. उन ऐप्स की सूची बनाइए जो आपके स्टोरफ़्रंट पर कुछ जोड़ते हैं। जैसे रिव्यू, चैट, पॉप-अप, अपसेल, लॉयल्टी, एनालिटिक्स और ऐड्स पिक्सल। जो ऐप सिर्फ़ एडमिन में काम करते हैं, उन पर कोई असर नहीं पड़ेगा।
  2. अपने थीम एडिटर में App embeds देखिए। अगर कोई ऐप वहाँ दिखता है और चालू है, तो वह नए तरीके का इस्तेमाल कर रहा है और ठीक है।
  3. पेज सोर्स देखिए। अपना स्टोर खोलिए, पेज सोर्स देखिए और asyncLoad खोजिए। ज़्यादातर स्टोर्स में script tag के URL इसी ब्लॉक में लिखे होते हैं। यहाँ दिए गए हर डोमेन से आमतौर पर किसी ऐप का पता चल जाता है।
  4. ऐप डेवलपर से पूछिए। “क्या आपका ऐप script tags इस्तेमाल करता है, और क्या वह 1 मार्च 2027 के बाद भी काम करेगा?” यह ऐसा सवाल है जिसका जवाब एक अच्छी तरह मेंटेन किया गया ऐप एक लाइन में दे सकता है।

Shopify सालों से ऐप्स को theme app extensions की ओर ले जा रहा है, इसलिए ज़्यादातर अच्छी तरह मेंटेन किए जाने वाले ऐप पहले से ठीक हैं। जोखिम पुराने ऐप्स में है, उन कस्टम ऐप्स में जो किसी ने आपके लिए सालों पहले बनाए थे, और उन ऐप्स के बचे हुए हिस्सों में जिन्हें आप अब इस्तेमाल नहीं करते।

Script tags की जगह क्या लेगा

  • App embed blocks, जो theme app extension का हिस्सा हैं, उन सभी चीज़ों के लिए जो पेज पर दिखती हैं। आप इन्हें थीम एडिटर में चालू करते हैं, यानी अब आखिरकार आप इन्हें देख सकते हैं।
  • Web pixels उन स्क्रिप्ट्स के लिए जो सिर्फ़ एनालिटिक्स या कन्वर्ज़न डेटा इकट्ठा करती हैं। ये सैंडबॉक्स में चलते हैं, और ऐप के इन्हें सपोर्ट करने के बाद आपको कुछ नहीं करना पड़ता।

अगर कोई ऐप अपडेट नहीं होगा

उसे मार्च से पहले बदल दीजिए, या उसका फ़ीचर दोबारा बनवा लीजिए। कस्टम ऐप के लिए आमतौर पर काम यह होता है कि स्क्रिप्ट को theme app extension में ले जाया जाए, या अगर वह सिर्फ़ ट्रैकिंग करती है तो web pixel में। इसी दौरान, जो ऐप आपने अनइंस्टॉल कर दिए हैं उनके script tags भी हटा दीजिए; scriptTagDelete mutation अब भी काम करता है।

अगर आपके पास कोई कस्टम Shopify ऐप है जिसे माइग्रेट करना है, या आपको पक्का पता नहीं कि आपके स्टोर पर क्या-क्या लोड हो रहा है, तो हमें अपने स्टोर का पता भेजिए और हम बताएँगे कि हमें क्या मिला। हमारे Shopify के काम के बारे में ज़्यादा जानकारी इस पेज पर है।

मुझे आपका ईमेल पता चाहिए, ताकि जब भी कोई नई पोस्ट प्रकाशित हो, मैं आपको ऐसी ही और पोस्ट भेज सकूँ।
