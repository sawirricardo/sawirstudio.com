# Sawirly

Сервис сокращения ссылок с упором на приватность: без отслеживания и со ссылками, срок действия которых можно ограничить

Большинство сервисов сокращения ссылок отслеживают клики, показывают рекламу или собирают персональные данные. Sawirly так не делает: он не записывает и не фиксирует по цифровому отпечатку ваш IP-адрес, местоположение и браузер, а каждая ссылка по умолчанию чистая и приватная.

Для ссылки можно задать собственный алиас, указать даты начала и окончания действия или сделать её одноразовой — она сработает только при первом переходе. Sawirly бесплатен для личного использования, а разработчикам доступен удобный API, который уважает приватность.
