# Плагины для WordPress

![Иконки двенадцати плагинов Sawir Studio для WordPress](https://sawirstudio.com/assets/images/projects/wordpress-plugins.webp)

## О проекте

На WordPress работает значительная часть сайтов в интернете, а на WooCommerce — многие интернет-магазины. Мы выпускаем бесплатные плагины для обеих платформ на WordPress.org. Каждый из них хорошо решает одну задачу, поэтому владелец сайта может добавить только то, что ему нужно, и не покупать набор лишних функций. У каждого плагина ниже есть своя страница с описанием возможностей и ответами на частые вопросы.

## Для магазинов на WooCommerce

- **[Sawir Renew](https://sawirstudio.com/ru/projects/wordpress-plugins/sawir-renew/).** Подписки для WooCommerce: регулярные платежи, пробные периоды, плата за подключение, пауза и пропуск, смена тарифа, напоминания о неоплате и умные повторные попытки списания. Всё бесплатно.
- **[Sawir Referral](https://sawirstudio.com/ru/projects/wordpress-plugins/sawir-referral/).** Реферальная программа «дарите и получайте»: друзья получают скидку, а тот, кто их пригласил, — купон в награду. Делиться можно по коду или ссылке, в первую очередь через WhatsApp.
- **[Sawir Pulse](https://sawirstudio.com/ru/projects/wordpress-plugins/sawir-pulse/).** Социальное доказательство только на основе реальной активности: недавние заказы, посетители онлайн и отзывы в виде небольших уведомлений в углу экрана.
- **[Sawir Restock Notifier](https://sawirstudio.com/ru/projects/wordpress-plugins/sawir-restock-notifier-for-woocommerce/).** Покупатели могут подписаться на письмо о том, что товар, которого не было в наличии, снова появился.
- **[Sawir Min Max Quantities](https://sawirstudio.com/ru/projects/wordpress-plugins/sawir-min-max-quantities-for-woocommerce/).** Правила минимального и максимального количества для отдельного товара, для категории и для заказа в целом.
- **[Sawir Product Image Zoom](https://sawirstudio.com/ru/projects/wordpress-plugins/sawir-product-image-zoom-for-woocommerce/).** Лайтбокс с навигацией и увеличением по клику для галерей товаров.
- **[Sawir Variation Gallery Tools](https://sawirstudio.com/ru/projects/wordpress-plugins/sawir-variation-gallery-tools-woocommerce/).** Отдельные галереи изображений для каждого варианта товара. Работает в паре с Product Image Zoom.

## Для любого сайта на WordPress

- **[Sawir Insights](https://sawirstudio.com/ru/projects/wordpress-plugins/sawir-insights/).** Тепловые карты, записи сессий, опросы, воронки и аналитика форм. Все данные хранятся на вашем собственном сервере.
- **[Sawir Social Scheduler](https://sawirstudio.com/ru/projects/wordpress-plugins/sawir-social-scheduler/).** Напишите публикацию один раз и запланируйте её в 27 соцсетей прямо из wp-admin: с правками для каждого канала, цепочками постов, медиафайлами и предпросмотром.
- **[Sawir Live Translate](https://sawirstudio.com/ru/projects/wordpress-plugins/sawir-live-translate/).** Переводите любую страницу сайта прямо на лету, сохраняйте переведённые строки и позвольте посетителям переключать язык.
- **[Sawir Media Folders](https://sawirstudio.com/ru/projects/wordpress-plugins/sawir-media-folders/).** Быстрые папки без ограничений для медиатеки с перетаскиванием файлов.
- **[Sawir Role Capabilities Manager](https://sawirstudio.com/ru/projects/wordpress-plugins/sawir-role-capabilities-manager/).** Создавайте собственные роли пользователей и управляйте тем, что может делать каждая роль.

## Как мы подошли к задаче

Плагины работают внутри чужого бизнеса, поэтому мы придерживаемся нескольких правил. Каждый плагин бесплатен на WordPress.org и решает одну задачу. Данные остаются на сервере владельца сайта: Insights записывает сессии без сторонних сервисов, а Social Scheduler хранит токены в WordPress. И без обмана: Pulse показывает только ту активность, которая действительно была, а Renew бесплатно предлагает функции подписок, за которые другие берут деньги.

**Технологии** PHP, WordPress и WooCommerce
