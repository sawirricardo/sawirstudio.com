Sawir Live Translate

Sawir Live Translate переводит страницы прямо на месте: выберите язык, переведите видимый текст автоматически, сохраните результат и добавьте для посетителей переключатель языков.

Скачать бесплатно на WordPress.org

Что он умеет

Откройте любую страницу сайта, нажмите «Translate this page» на панели администратора, выберите язык перевода и либо переведите все видимые строки автоматически (через бесплатный сервис машинного перевода), либо отредактируйте перевод вручную, наблюдая, как страница обновляется в реальном времени.

Сохранённые переводы подставляются на сервере прямо в HTML-ответ (это удобно для SEO: нет мигания непереведённого текста, а в head добавляются альтернативные ссылки hreflang). Посетители переключают язык с помощью переключателя на ссылках (внизу справа).

В URL используется языковой префикс в пути: например, /es/about для испанского и /about для исходного языка (он остаётся основным и без префикса). Язык определяется в таком порядке: путь /es/ → ?lang=es → сохранённый cookie → заголовок Accept-Language браузера → исходный язык. Для корневого адреса и URL без префикса язык браузера посетителя определяется автоматически, без перенаправления (отправляется заголовок Vary, чтобы общие кэши работали корректно).

1. Откройте Settings → Live Translate: укажите исходный язык и отметьте языки, которые хотите предложить посетителям. 2. Откройте любую страницу сайта и нажмите «🌐 Translate this page» на панели администратора. 3. Выберите язык, нажмите «Auto-translate empty» (или отредактируйте строки), затем «Save». 4. Посетители пользуются переключателем (внизу справа); у каждого языка свой URL вида /xx/.

Примечание: языковые префиксы в пути предполагают установку в корне домена и отсутствие страницы верхнего уровня, слаг которой совпадает с двухбуквенным кодом языка.

Вопросы

Чем он отличается от аналогов?

Многоязычные фреймворки, такие как WPML, Polylang и TranslatePress, рассматривают переведённый контент как полноценную часть структуры сайта: у них отдельные процессы редактирования для каждого языка, сервисы перевода и глубокая интеграция с конструкторами страниц и WooCommerce. Sawir Live Translate намеренно легче: откройте страницу, переведите то, что на ней видно (автоматически или вручную), и отдавайте её по URL с языковым префиксом и тегами hreflang. Если вы создаёте полностью многоязычный сайт с переведёнными меню, товарами и редакционными процессами, выберите один из этих фреймворков. Если же нужно, чтобы существующие страницы можно было прочитать на другом языке уже сегодня, именно для этого и создан наш плагин.

Я переключаю язык, но ничего не меняется

Почти всегда это значит, что для этого языка ещё нет сохранённых переводов. Откройте Settings → Live Translate → Saved translations: если языка нет в списке (или у него 0 строк), снова откройте редактор страницы, выполните автоперевод и нажмите «Save». Пока вы этого не сделаете, предпросмотр в редакторе не сохраняется.

Некоторые строки остаются непереведёнными

Редактор на странице видит только строки той страницы, которую вы открыли. Текст, который находится на других страницах, нужно переводить вместе с ними — или запустить сканирование всего сайта. Строки, которые слайдеры или скрипты добавляют после загрузки страницы, возможно, придётся добавить вручную через «Edit all site strings».

Я изменил(а) контент, и перевод пропал

Переводы привязываются к точному исходному тексту. Если вы переписали предложение, переведите новую версию и сохраните её ещё раз.

Хорошо сочетается с

  • Sawir Insights: показывает, как посетители пользуются вашим сайтом: тепловые карты, записи сеансов, опросы, воронки и аналитика форм. Все данные хранятся на вашем сервере.
  • Sawir Media Folders: добавляет папки в медиатеку WordPress, сколько нужно, а файлы можно раскладывать перетаскиванием.
