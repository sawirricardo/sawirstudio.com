Sawir Media Folders

Sawir Media Folders добавляет в медиатеку WordPress папки в любом количестве: файлы раскладываются по ним простым перетаскиванием.

Скачать бесплатно на WordPress.org

Что он умеет

Упорядочьте медиатеку с помощью папок и подпапок. Без ограничений на число папок и без платных тарифов.

  • Неограниченное число папок и подпапок — без лимитов.
  • Быстро — всё дерево папок загружается двумя запросами к базе данных, независимо от размера медиатеки. Для фильтрации используется встроенный медиазапрос WordPress.
  • Безопасно — папки виртуальные (таксономия). Физически файлы не перемещаются, поэтому ни одна ссылка не перестанет работать. Удаление папки никогда не удаляет файлы.

Вопросы

Чем он отличается от аналогов?

FileBird, HappyFiles и Real Media Library — зрелые плагины для работы с папками с продуманными дополнительными возможностями, но в их бесплатных версиях обычно ограничено число папок, которые можно создать. Sawir Media Folders намеренно решает узкую задачу: виртуальные папки, перетаскивание и быстрая фильтрация — без лимитов и без платной версии. Папки реализованы как таксономия, поэтому файлы физически не перемещаются и ни одна ссылка не ломается. Если вам нужны дополнительные функции, например персональные папки для пользователей или интеграции с галереями, платные решения оправдывают свою цену. Если же нужно просто навести порядок в медиатеке, этот плагин остаётся бесплатным и быстрым.

Изменятся ли адреса моих файлов из-за папок?

Нет. Папки нужны только для организации файлов (это скрытая таксономия для вложений). Файлы остаются там же, куда их загрузил WordPress.

Что будет, если отключить или удалить плагин?

Ничего не сломается. Ваши файлы останутся нетронутыми, а распределение по папкам просто перестанет отображаться. Если снова активировать плагин, всё вернётся.

Есть ли ограничение на число папок в бесплатной версии?

Платной версии нет. Всё бесплатно и без ограничений.

Хорошо сочетается с

  • Sawir Role Capabilities Manager: позволяет создавать собственные роли пользователей и точно определять, что может делать каждая роль, новая или встроенная.
  • Sawir Insights: показывает, как посетители пользуются вашим сайтом: тепловые карты, записи сеансов, опросы, воронки и аналитика форм. Все данные хранятся на вашем сервере.
