# Script tags в Shopify перестанут работать 1 марта 2027 года. Что делать владельцам магазинов

1 марта 2027 года Shopify перестанет подгружать script tags в онлайн-магазины. Всё, что на вашем сайте до сих пор загружается таким способом, будь то виджет отзывов, чат или пиксель отслеживания, просто исчезнет. Никаких громких ошибок не будет. Элементы просто пропадут.

О своём решении Shopify объявил в [августе 2026 года](https://shopify.dev/changelog/posts/online-store-script-tags-deprecation). Разберём, что это значит, если у вас есть магазин.

## Что такое script tag

Script tag — это способ, с помощью которого приложение добавляет JavaScript в витрину магазина через API, не затрагивая тему оформления. Приложениям это нравилось, но в этом же и проблема: script tags не отображаются в редакторе тем, поэтому увидеть или отключить их там нельзя. Иногда удалённые приложения оставляли свои скрипты на месте.

## Сроки

- **1 октября 2026 года:** приложения больше не смогут создавать и обновлять script tags ни в одной версии API. Уже существующие продолжат работать.
- **1 марта 2027 года:** Shopify прекращает загружать script tags онлайн-магазина.

Script tags на странице статуса заказа были отключены раньше и по отдельному графику. Если что-то там перестало отображаться, причина в этом.

## Как проверить свой магазин

Shopify не показывает владельцам магазинов список script tags, поэтому проверять придётся самостоятельно:

1. **Составьте список приложений, которые что-то добавляют на витрину.** Отзывы, чат, всплывающие окна, допродажи, программы лояльности, аналитика, рекламные пиксели. Приложения, которые работают только в админ-панели, это не затрагивает.
2. **Откройте раздел App embeds в редакторе тем.** Если приложение есть в списке и включено, оно использует новый метод, и всё в порядке.
3. **Посмотрите исходный код страницы.** Откройте магазин, перейдите к исходному коду и найдите `asyncLoad`. В большинстве магазинов адреса script tags перечислены именно в этом блоке. Каждый домен там обычно указывает на какое-то приложение.
4. **Спросите разработчика приложения.** «Использует ли ваше приложение script tags и будет ли оно работать после 1 марта 2027 года?» Если приложение поддерживается, ответить на этот вопрос можно одной строкой.

Shopify уже несколько лет подталкивает разработчиков к theme app extensions, поэтому у большинства хорошо поддерживаемых приложений всё в порядке. Риск связан со старыми приложениями, с кастомными приложениями, которые кто-то написал для вас много лет назад, и с остатками приложений, которыми вы больше не пользуетесь.

## Что приходит на смену script tags

- **App embed blocks** — часть theme app extension — для всего, что отображается на странице. Их включают в редакторе тем, так что теперь их наконец можно увидеть.
- **Web pixels** для скриптов, которые только собирают данные аналитики или конверсий. Они работают в изолированной среде, и после того как приложение их поддержит, от вас ничего не потребуется.

## Если приложение обновлять не будут

Замените его до марта или закажите разработку нужной функции заново. Для кастомного приложения это обычно сводится к переносу скрипта в theme app extension или в web pixel, если он только отслеживает данные. Заодно удалите script tags приложений, которые вы убрали: мутация `scriptTagDelete` по-прежнему работает.
