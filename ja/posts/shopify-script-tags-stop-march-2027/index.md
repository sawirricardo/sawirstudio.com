# Shopify のスクリプトタグは2027年3月1日に動作停止。ストア運営者が今すべきこと

2027年3月1日、Shopify はオンラインストアへのスクリプトタグの読み込みを停止します。いまだにその方法で読み込んでいるもの、たとえばレビューウィジェット、チャットの吹き出し、トラッキングピクセルなどは、単に表示されなくなります。エラーが出るわけではなく、気づかないうちに機能が消えてしまいます。

Shopify は[2026年8月](https://shopify.dev/changelog/posts/online-store-script-tags-deprecation)にこの変更を発表しました。ストアを運営されている方にとって何が起きるのかを、ここでご説明します。

## スクリプトタグとは

スクリプトタグとは、アプリが API を通じて、テーマに手を加えずにストアフロントへ JavaScript を追加する仕組みです。アプリ開発者に好まれてきた理由はそこにありますが、問題点でもあります。スクリプトタグはテーマエディタに表示されないため、そこで確認することも、オフにすることもできません。アンインストールしたアプリのスクリプトタグが残ってしまうこともあります。

## スケジュール

- **2026年10月1日：** アプリは、どの API バージョンでもスクリプトタグを新規作成・更新できなくなります。既存のものは引き続き動作します。
- **2027年3月1日：** Shopify がオンラインストアのスクリプトタグの読み込みを停止します。

注文ステータスページのスクリプトタグは、これより前に別のスケジュールで廃止されています。そのページで以前から何かが表示されなくなっている場合は、それが理由です。

## ストアの確認方法

Shopify では、スクリプトタグの一覧を店舗側で確認することはできないため、次の方法で調べる必要があります。

1. **ストアフロントに何かを表示しているアプリを書き出します。** レビュー、チャット、ポップアップ、アップセル、ロイヤルティ、アクセス解析、広告ピクセルなどが対象です。管理画面でのみ動作するアプリは影響を受けません。
2. **テーマエディタの「アプリの埋め込み」を確認します。** アプリがそこに表示され、オンになっていれば、新しい方式を使っているので問題ありません。
3. **ページのソースを確認します。** ストアを開いてページのソースを表示し、`asyncLoad` を検索してください。多くのストアでは、そのブロックの中にスクリプトタグの URL が並んでいます。そこに出てくる各ドメインは、たいてい何らかのアプリに対応しています。
4. **アプリの開発元に問い合わせます。**「御社のアプリはスクリプトタグを使っていますか。2027年3月1日以降も動作しますか」。きちんとメンテナンスされているアプリであれば、一言で答えてもらえる質問です。

Shopify は何年も前からアプリにテーマアプリ拡張機能への移行を促してきたため、適切に保守されているアプリのほとんどはすでに対応済みです。リスクがあるのは、古いアプリ、何年も前に誰かが作ったカスタムアプリ、そして使わなくなったアプリの残骸です。

## スクリプトタグに代わるもの

- **アプリ埋め込みブロック**（テーマアプリ拡張機能の一部）は、ページ上に表示されるものすべてに使えます。テーマエディタでオンにするので、ようやく目で確認できるようになります。
- **ウェブピクセル** は、アクセス解析やコンバージョンのデータを収集するだけのスクリプト向けです。サンドボックス内で動作し、アプリが対応すれば、お客様側での作業は不要です。

## アプリが更新されない場合

3月までに別のアプリに置き換えるか、その機能を作り直してください。カスタムアプリの場合、多くはスクリプトをテーマアプリ拡張機能に移す作業になります。計測だけを行うものであれば、ウェブピクセルに移します。あわせて、アンインストールしたアプリのスクリプトタグも削除しておきましょう。`scriptTagDelete` ミューテーションは引き続き利用できます。

移行が必要なカスタム Shopify アプリをお持ちの場合や、ストアで何が読み込まれているかわからない場合は、[ストアのアドレスをお送りください](https://sawirstudio.com/ja/contact/)。調査結果をお知らせします。Shopify に関する当社の取り組みについては、[こちらのページ](https://sawirstudio.com/ja/shopify/)をご覧ください。
