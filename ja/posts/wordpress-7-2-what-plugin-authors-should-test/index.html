WordPress 7.2 は 12 月 8 日にリリース予定：自社プラグインで確認していること

WordPress 7.2 は 2026 年 12 月 8 日のリリースを予定しています。最初のリリース候補（RC）は 11 月 17 日に公開される予定で、このタイミングで機能一覧が確定し、開発者向けノートをすべてまとめた Field Guide も公開されます。それまでは、ベータ版が、プラグインの問題を最も手軽に見つけられる場です。

私たちは WordPress.org で 12 個の無料プラグインを公開・保守しています。以下は、私たち自身が使っているチェックリストです。執筆時点ではまだ提案段階の項目も含まれていますので、最終的な内容は Field Guide でご確認ください。

今すぐテストする方法

  • WP-CLI：テスト用サイトで wp core update --version=7.2-beta4 を実行します。最新のベータ版または RC があれば、そのバージョンを指定してください。
  • WordPress Beta Tester プラグイン：「Bleeding edge」と「Beta/RC Only」に設定します。
  • WordPress Playground：何もインストールせず、ブラウザ上で動作を確認できます。

本番サイトでは絶対に行わないでください。WP_DEBUG と WP_DEBUG_LOG を有効にして、非推奨の通知を確認しましょう。早い段階の警告は、ほとんどがここに表示されます。

確認している項目

アプリケーションパスワード

7.2 ではアプリケーションパスワードが強化されます。ローカル環境や HTTPS 環境の判定の改善、追加時のメール通知、デフォルトロールのより安全な扱いなどです。お使いのプラグインや、お客様のツールがこの方法で REST API に認証している場合は、一連の流れを最初から最後まで試してください。

Secrets API

認証情報を暗号化して保存するための、コア標準の仕組みです。これによって、プラグインが API キーを平文のオプションとして保存することがなくなります。7.2 での導入が提案されており、管理画面は 7.3 に持ち越される見込みです。プラグインで API キーを保存している場合は、Field Guide での扱いに注目してください。提供が始まったら、キーはそこに保存するのが正解になります。当社の無料プラグインには、現在サードパーティのキーを保存するものはないため、当社にとってはお客様向けの開発案件に関わる話です。

Sudo モード

予定されている機能で、権限の高い操作の前に、ログイン中のユーザーにパスワードの再確認を求めるものです。プラグイン独自の画面や AJAX でそのような操作を行っている場合は、途中でコアから再確認を求められたときの挙動をテストしてください。

Interactivity API のルーター

クライアント側のナビゲーションを監視するための新しいルーターが追加され、非推奨となった state.navigation.hasStarted と hasFinished の組に代わります。また、信頼できるマークアップを描画するための data-wp-html ディレクティブも追加されます。

管理画面のアイコンと通知

管理バーとメニューの Dashicons が SVG アイコンに置き換えられ、管理画面の通知はスクリーンリーダーでより適切に読み上げられるようになります。プラグインでメニューアイコンのスタイルを指定している場合や、管理画面の CSS で Dashicons のクラスを対象にしている場合は、ベータ版で表示を確認してください。

DataViews とサイトエディター

プラグインは、サイトエディター内に独自の画面を登録できるようになり、DataViews のフィールドやレイアウトをサーバー側から制御できるようになります。ここで何かが動かなくなることはありませんが、プラグインに一覧画面がある場合は、今後の方向性を把握しておくとよいでしょう。

テストの後に

readme の「Tested up to」は、実際にテストを終えてから更新してください。事前に書き換えるのは避けましょう。直近のメジャーリリースでテストされていないプラグインには、WordPress.org でユーザー向けに警告が表示され、その警告はインストール数の減少につながります。当社のプラグインは現在「Tested up to: 7.1」となっており、RC で問題がないことを確認できしだい 7.2 に更新します。

新しいデフォルトテーマ Ipsum も同時に提供されます。プラグインがフロントエンドに何かを出力する場合は、このテーマで表示を確認してください。新規サイトの見た目は、このテーマが基準になります。

7.2 に向けて更新が必要なプラグインや、誰もメンテナンスしていないカスタムプラグインがありましたら、お気軽にご相談ください。
