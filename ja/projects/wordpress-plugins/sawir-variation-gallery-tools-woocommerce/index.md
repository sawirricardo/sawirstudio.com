# Sawir Variation Gallery Tools

![Sawir Variation Gallery Tools のバナー](https://sawirstudio.com/assets/images/plugins/sawir-variation-gallery-tools-woocommerce-banner.webp)

Sawir Variation Gallery Tools は、商品のバリエーションごとに専用のギャラリーを設定できるプラグインです。赤を選べば、赤い商品の写真が表示されます。Sawir Product Image Zoom と組み合わせて使うことで、さらに便利になります。

[WordPress.org から無料で入手](https://wordpress.org/plugins/sawir-variation-gallery-tools-woocommerce/)

## 主な機能

Sawir Variation Gallery Tools for WooCommerce は、WooCommerce の商品編集画面にある各バリエーションに「Additional variation images（バリエーション追加画像）」フィールドを追加します。

お客様が商品ページでバリエーションを選択すると、そのバリエーションに保存された画像が WooCommerce の商品ギャラリーに追加されます。

ストア管理者は、WooCommerce > Variation Images から、バリエーションの追加画像を一括でエクスポート・インポートすることもできます。CSV エクスポートには、各バリエーションの ID、SKU、属性、追加画像の ID、画像の URL が含まれます。CSV インポートでは、取り込んだ行の画像を置き換えることも、追加することもできます。

このプラグインは Sawir Product Image Zoom for WooCommerce と連携します: https://wordpress.org/plugins/sawir-product-image-zoom-for-woocommerce/

バリエーション画像は標準の WooCommerce ギャラリー画像として追加されるため、Sawir Product Image Zoom for WooCommerce のライトボックスやズーム機能にもそのまま反映されます。

## よくある質問

### 他の選択肢と比べてどうですか？

Additional Variation Images Gallery や Iconic WooThumbs などのプラグインは、バリエーションごとの画像に加えて、スライダー、レイアウト、動画に対応した独自のギャラリープレーヤーを備えています。一方、Sawir Variation Gallery Tools はバリエーションごとの画像を保存し、標準の WooCommerce ギャラリーに渡すだけです。そのため、お使いのテーマや連携プラグイン（Sawir Product Image Zoom など）は、これまでどおり変更なしで動作します。さらに、ストア管理者は CSV のエクスポート・インポートで一括編集もできます。新しいギャラリー体験を求める場合はスイート型のプラグインを、今お使いのギャラリーにバリエーション画像を加えたい場合は、機能を絞ったこのプラグインをおすすめします。

### Sawir Product Image Zoom for WooCommerce と併用できますか？

はい、併用できます。このプラグインで追加したバリエーション画像は、標準の WooCommerce 商品ギャラリーのマークアップを使用しているため、Sawir Product Image Zoom for WooCommerce でそのまま動作します。

### バリエーション画像を一括で更新、エクスポート、インポートできますか？

はい、できます。WooCommerce > Variation Images から CSV のエクスポートやインポートが可能です。インポートでは、`variation_id` または `variation_sku` でバリエーションを照合します。インポートする行には、メディアライブラリにある既存の添付ファイル ID か URL を指定できます。
