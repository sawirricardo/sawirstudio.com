# Sawir Product Image Zoom

![Sawir Product Image Zoom のバナー](https://sawirstudio.com/assets/images/plugins/sawir-product-image-zoom-for-woocommerce-banner.webp)

Sawir Product Image Zoom は、商品写真をライトボックスで表示します。矢印でギャラリー内を移動でき、クリックすると細部を拡大して確認できます。

[WordPress.org で無料入手](https://wordpress.org/plugins/sawir-product-image-zoom-for-woocommerce/)

## 主な機能

Sawir Product Image Zoom for WooCommerce は、WooCommerce 標準の商品ギャラリーで画像をクリックしたときの動作を、見たい画像に集中できるライトボックス表示に置き換えます。

主な機能：

- 商品画像を全画面のライトボックスで表示します。
- 前へ・次へのナビゲーションに対応しています。
- Esc キー、左矢印キー、右矢印キーによるキーボード操作に対応しています。
- タッチデバイスでのスワイプ操作に対応しています。
- クリックで拡大でき、拡大中はドラッグで表示位置を移動できます。
- 従来型の WooCommerce 商品ギャラリーにも、ブロックベースの商品ギャラリーにも対応しています。

CSS と JavaScript は、商品の個別ページでのみ読み込まれます。

## よくある質問

### 他の選択肢と比べてどうですか？

Iconic WooThumbs や YITH Zoom Magnifier のようなギャラリースイートは、レイアウト、スライダー、動画、ズームなど、WooCommerce の商品ギャラリー全体を置き換えます。Sawir Product Image Zoom が変えるのは、お客様が画像をクリックしたときの動作ひとつだけです。テーマのギャラリーはそのまま使え、キーボード操作、スワイプ、クリックでの拡大に対応した軽快なライトボックスを、商品ページでのみアセットを読み込む形でお使いいただけます。ギャラリー自体を作り替えたい場合はスイートを、ギャラリーには満足していて見せ方だけを改善したい場合は、より軽量なこちらをお選びください。

### WooCommerce は必須ですか？

はい。このプラグインは WooCommerce の商品ギャラリー向けに作られています。

### サイト全体でアセットを読み込みますか？

いいえ。アセットは WooCommerce の商品個別ページでのみ読み込まれます。

### タッチデバイスに対応していますか？

はい。タッチデバイスでは、ライトボックス内でのスワイプ操作と、拡大した画像の移動に対応しています。
