# Sawir Insights

![Sawir Insights のバナー](https://sawirstudio.com/assets/images/plugins/sawir-insights-banner.webp)

Sawir Insights は、ヒートマップ、セッション録画、アンケート、ファネル、フォーム分析で訪問者のサイト上での行動を可視化し、そのデータをすべてお客様ご自身のサーバーに保管します。

[WordPress.org で無料入手](https://wordpress.org/plugins/sawir-insights/)

## 主な機能

Sawir Insights は WordPress 向けの行動分析プラグインです。ヒートマップ、セッション録画、アンケート、フィードバックウィジェット、フォーム分析、コンバージョンファネル、そしてそれらをまとめるダッシュボードを備えています。

マルチサイト環境では、各サイトが分析の計測と設定をそれぞれ独立して行います。

ひとことで言えば、Hotjar や Microsoft Clarity に代わるセルフホスト型のツールで、訪問者のデータは自社のデータベースに残ります。

このプラグインを作った理由はシンプルです。この分野の既存ツールは優れていますが、訪問者の行動のあらゆる記録を他社のサーバーに送ることで成り立っています。特に EU 圏のサイトでは、これは抵抗があるか、場合によっては運用が難しいことも少なくありません。そこで、同じ種類のツールを、データが収集したサイトの外に出ない形で作りたいと考えました。このプラグインはその制約を軸に作られています。データベースも、アップロードディレクトリも、保持ルールも、すべてお客様のものです。裏側に SaaS はなく、アカウントの作成も不要で、外部への自動通信も一切ありません。

### 主な機能

- クリック、マウス移動、スクロールのヒートマップを、実際に公開中のページ上に表示します。デスクトップ、タブレット、モバイルごとに分けて確認できます。
- セッション録画を wp-admin 上で再生できます。入力値は常にマスクされ、録画はお客様が有効にするまでオフのままです。
- ポップアップ式のアンケートと、常時表示のフィードバックタブを用意しています。URL、デバイス、トラフィックの割合、ページ滞在時間、スクロール深度、離脱意図で表示対象を絞り込めます。
- フォーム分析では、どこでためらったか、何が未入力のままか、どこで離脱したかが分かります。記録するのはセレクターとタイミングだけで、入力内容は一切取得しません。
- 順序を設定できるコンバージョンファネルと、日次レポートを備えています。
- トラフィックの KPI と前期間との差分、日次トレンドのグラフ、さらにデバイス、ブラウザ、ページ、参照元、キャンペーン、ファネル、録画の内訳を表示するダッシュボードです。

### あえて行わないこと

導入前に、そのツールが「やらないこと」を知っておいていただきたいと考えています。

- IP アドレスは保存しません。ハッシュ化も切り詰めもせず、一切保存しません。
- フォームの入力値は決して記録しません。取得の仕組みが送るのはメタデータだけなので、漏えいするものがそもそもありません。
- CDN からは何も読み込まず、CDN へは何も送信しません。rrweb のリプレイライブラリはプラグインに同梱されています。
- 生データを無期限に保持することはありません。イベントは集計され、お客様が設定する保持スケジュールに従って削除されます。録画には独自の保持期間と、古いものから順に削除するディスク容量の上限があります。ホスティングのディスクを知らないうちに埋めてしまうプラグインは、よいプラグインとは言えないからです。

フロントエンドのトラッカーは小さな素の JavaScript で、`sendBeacon` でまとめて送信し、サンプリングも調整できます。録画のサンプリング対象にならなかった訪問者は、リプレイライブラリをダウンロードすることもありません。

### プライバシーへの姿勢

Do Not Track はデフォルトで尊重されます。同意モード API（`window.swinsConsent`）により、すでにお使いの同意管理ツールと連携できます。セッション、イベント、録画は、WordPress 標準の個人データのエクスポート機能および消去機能にも対応しています。お客様の具体的な運用が GDPR に準拠しているかどうかは、通知内容や法的根拠によって決まります。この部分はプラグインでは代行できませんが、データ最小化のための対応は済んでいます。

## よくある質問

### 他の選択肢と比べてどうですか？

Hotjar や Microsoft Clarity のようなホスト型の分析サービスは、無料枠も充実した優れたツールです。ただしその仕組みは、訪問者の行動の記録を各社のサーバーに送ることで成り立っています。Sawir Insights は、そうしたサイトをまたぐ基盤を使わず、すべてをお客様ご自身のサイトで収集、保存、閲覧するという一点を条件にしています。追加機能が欲しく、第三者による処理が気にならない場合はホスト型サービスを、訪問者のデータがサーバーの外に出ることが許容できない場合は Sawir Insights をお選びください。録画とヒートマップはお客様ご自身のデータベースとアップロードディレクトリに保存されるため、SaaS の場合以上に保持期間の設定が重要になります。

### Sawir Insights は GDPR に準拠していますか？

このプラグインは、プライバシーに配慮した運用を前提に作られています。データはお客様のサーバーに残り、IP アドレスは一切保存されず、保持期間は設定でき、Do Not Track も尊重され、WordPress のエクスポート機能と消去機能にも対応しています。ただし、準拠できるかどうかは、設定、通知内容、法的根拠、同意の実装によって決まります。ご自身のサイトについては、資格のある専門家にご相談ください。

### Hotjar や Microsoft Clarity とは何が違いますか？

それらはホスト型のサービスで、高機能なツールですが、訪問者の行動は各社の規約のもとで各社のサーバーに記録されます。Sawir Insights は、ヒートマップ、セッション録画、アンケート、ファネル、フォーム分析という同じ分野をカバーしつつ、すべてをお客様ご自身のサーバーに保管するプラグインです。アカウントも外部サービスも不要で、データが共有されることもありません。

### 訪問者のデータはサーバーの外に出ますか？

いいえ。このプラグインは、行動データを Sawir Studio にも他の分析プロバイダーにも一切送信しません。イベントは WordPress のデータベースに、録画ファイルは保護されたアップロードディレクトリの下に保存されます。
