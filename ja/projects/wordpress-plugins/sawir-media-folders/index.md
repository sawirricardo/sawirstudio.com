# Sawir Media Folders

![Sawir Media Folders のバナー](https://sawirstudio.com/assets/images/plugins/sawir-media-folders-banner.webp)

Sawir Media Folders は、WordPress のメディアライブラリにフォルダを追加するプラグインです。フォルダは必要なだけ作成でき、ドラッグ&ドロップでファイルを整理できます。

[WordPress.org で無料入手](https://wordpress.org/plugins/sawir-media-folders/)

## 主な機能

メディアライブラリを、フォルダとサブフォルダで整理できます。フォルダ数の上限も、有料プランへの誘導もありません。

- **フォルダとサブフォルダは無制限**：上限はありません。
- **高速**：ライブラリの規模に関係なく、フォルダツリー全体をデータベースへの2回のクエリで読み込みます。絞り込みには WordPress標準のメディアクエリを使用しています。
- **安全**：フォルダは仮想的なもの（タクソノミー）です。実際のファイルは移動しないため、URL が壊れることはありません。フォルダを削除しても、ファイルは削除されません。

## よくある質問

### 他の選択肢と比べてどうですか？

FileBird、HappyFiles、Real Media Library は、充実した追加機能を備えた完成度の高いフォルダ系プラグインですが、無料版では作成できるフォルダ数に上限があるのが一般的です。Sawir Media Folders は、仮想フォルダ、ドラッグ&ドロップ、高速な絞り込みに機能を絞り、上限も有料プランもありません。フォルダはタクソノミーなので、ファイルが実際に移動することはなく、URL が壊れることもありません。ユーザーごとのフォルダやギャラリー連携などの追加機能が必要な場合は、有料のプラグインを選ぶ価値があります。ライブラリを整理できれば十分という場合は、このプラグインなら無料で、動作も軽快です。

### フォルダを作ると、ファイルの URL は変わりますか？

いいえ、変わりません。フォルダは整理のためだけのもの（添付ファイルに付く非表示のタクソノミー）で、ファイルは WordPress がアップロードした場所にそのまま残ります。

### プラグインを無効化または削除すると、どうなりますか？

問題は起きません。ファイルには一切手を加えず、フォルダの割り当てが表示されなくなるだけです。再び有効化すれば、元に戻ります。

### 無料版にはフォルダ数の上限がありますか？

有料版はありません。すべて無料で、無制限にご利用いただけます。
