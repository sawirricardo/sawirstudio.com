Sawir Role Capabilities Manager

Sawir Role Capabilities Manager は、独自のユーザー権限グループ（ロール）を作成し、新規・標準を問わず、各ロールで何ができるかを細かく設定できるプラグインです。

WordPress.org で無料入手

主な機能

Sawir Role Capabilities Manager は、「ユーザー」メニューの下に、管理者専用のロール権限設定画面を追加します。管理者は、ロールの作成、既存ロールからの権限のコピー、独自の権限キーの追加、既存ロールの権限管理を行えます。

よくある質問

他の選択肢と比べてどうですか？

この分野では、User Role Editor、Members、PublishPress Capabilities が定番のツールで、有料版ではコンテンツ制限、フロントエンドの保護、管理メニューの制御などが加わります。Sawir Role Capabilities Manager は、基本的な管理作業を「ユーザー」配下の1画面にまとめ、無料で提供します。ロールの作成、ロール間での権限のコピー、独自の権限キーの追加、既存ロールの編集ができます。コンテンツの制限や会員レベルの構築が必要な場合は Members や PublishPress を、ロールと権限をすっきり管理したいだけであれば、このプラグインで十分です。

あわせて使いたいプラグイン

  • Sawir Media Folders：WordPress のメディアライブラリにフォルダーを追加します。必要な数だけ作成でき、ドラッグ＆ドロップで整理できます。
  • Sawir Live Translate：ページをその場で翻訳します。言語を選んで表示中の内容を自動翻訳し、保存すれば、訪問者向けの言語切り替えも設置できます。
