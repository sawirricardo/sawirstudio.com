# Sawir Renew

![Sawir Renew のバナー](https://sawirstudio.com/assets/images/plugins/sawir-renew-banner.webp)

Sawir Renew は、WooCommerce のショップをサブスクリプションビジネスに変えるプラグインです。定期課金、無料トライアル、初期費用、スマートリトライに対応し、有料版で機能が制限されることもありません。

[WordPress.org から無料で入手](https://wordpress.org/plugins/sawir-renew/)

## 主な機能

拡張機能に料金を払わなくても、WooCommerce でサブスクリプションを販売できます。すべての機能が無料で、有料版はなく、使えない機能もありません。

### 商品と価格設定

- シンプルな商品タイプと、バリエーション付きのサブスクリプション商品タイプに対応
- N日・N週間・Nか月・N年ごとの課金に対応し、セール価格も設定可能
- 無料トライアル、初期費用、N回の支払いで終了するサブスクリプションに対応
- 更新日の統一（全員が毎月1日、またはお好きな日に更新）に対応。初回期間は日割り計算または無料にすることも可能
- 送料を初回のみにする設定や、「1お客様につき有効なサブスクリプションは1件まで」という制限に対応

### 2つの支払い方法

- **更新ごとの支払い（すべての決済ゲートウェイで利用可能）：** 更新日が来ると、お客様に支払いリンク付きの請求書が届きます。銀行振込、電子ウォレット、代金引換など、ストアで受け付けている方法をそのまま使えます。カードの自動課金が一般的でない市場に最適です。
- **Stripe による自動課金：** 公式の WooCommerce Stripe Gateway をお使いの場合、カードはチェックアウト時に保存され、更新時にオフセッションで自動的に課金されます。スマートリトライや、カードで認証が必要になった際の予備の支払いリンクにも対応しています。他のゲートウェイも同じアダプター規約に沿って連携できます（FAQ をご覧ください）。

### 深夜3時に起こされない更新処理

- すべてのタイミング処理は Action Scheduler 上で動作し、毎日の自動修復チェックも行います
- 督促の設定が可能：リトライ間隔、リマインダーの日程、猶予期間、自動キャンセル
- ステージング環境や複製サイトを検出し、サイトの URL が変わった時点で課金を一時停止します。忘れていたステージング用コピーによる二重課金を防ぎます
- 自動課金の前に、更新予告メールを送信

### お客様ご自身で手続きが可能

「マイアカウント」→「サブスクリプション」から、お客様ご自身でキャンセル（即時または期間終了時のどちらかをお選びいただけます）、一時停止と再開、更新のスキップ、早期更新、支払い方法や配送先住所の変更、プラン間のアップグレード・ダウングレード（アップグレード時は日割りで請求）ができます。

### 定期クーポン

サブスクリプション用クーポンは4種類あります。定期的に適用される割合・固定額の割引（最初のN回の支払いに限定することも可能）と、初期費用の割引です。WooCommerce 標準のクーポンは、これまでどおり最初の注文にのみ適用されます。

### 通知

お客様向けと管理者向けを合わせて13種類のメールがあり、サブスクリプションのあらゆる場面に対応します。それぞれオン・オフを切り替えられます。開発者は `swsb_notified` フックを使って、あらゆるイベントを他のチャネル（WhatsApp、SMS、Slack など）にも連携できます。

### 最新の WooCommerce に対応

HPOS にネイティブ対応（サブスクリプションは WooCommerce の注文ストレージに保存され、独自テーブルは使いません）。カート／チェックアウトブロックにも対応しています。管理画面の一覧と編集画面は WooCommerce 標準の注文画面をそのまま使用します。1時間ごとにキャッシュされるレポートページ（有効数、MRR、解約率、今後の更新、更新による売上）と REST API も備えています。

## よくある質問

### WooCommerce や Automattic と提携していますか？

いいえ。「WooCommerce」は Automattic の商標であり、本プラグインは、同社のネーミングガイドラインに沿って開発された、WooCommerce *向け*の独立したプラグインです。

### 自動更新に対応しているゲートウェイはどれですか？

標準で対応しているのは、公式の WooCommerce Stripe Gateway です。それ以外のゲートウェイは、更新ごとの支払いモードで動作し、期間ごとにお客様へ支払いリンクが届きます。開発者は2つのフィルターを使って、任意のゲートウェイに自動課金の対応を追加できます。

`swsb_order_supports_auto` — 親注文のゲートウェイが再利用可能な支払い方法を保存している場合に true を返します。`swsb_charge_renewal` — 更新注文をオフセッションで課金し、`true` または `WP_Error` を返します。

### WooCommerce Subscriptions と併用できますか？

いいえ。2つの課金エンジンを同時に動かすとお客様に二重課金してしまうため、WooCommerce Subscriptions が有効な場合、本プラグインは自身のエンジンを無効にして通知を表示します。

### ステージング環境ではどうなりますか？

サイトの URL が変わると、コピーがステージング環境か本番サイトかをご確認いただくまで、課金とお客様へのメール送信が自動的に停止します。「本番」を選ぶと、すべてのスケジュールが再構築されます。
