# WordPress プラグイン

![Sawir Studio の WordPress プラグイン 12 個のアイコン](https://sawirstudio.com/assets/images/projects/wordpress-plugins.webp)

## プロジェクトについて

WordPress はウェブの大きな割合を占めており、WooCommerce も数多くのショップを支えています。私たちは、その両方に向けた無料のプラグインを WordPress.org で公開しています。どのプラグインも一つの役割をしっかり果たすので、不要な機能がまとめて付いてくる高価なセットを買わなくても、必要なものだけを追加できます。以下の各プラグインには、機能とよくあるご質問への回答をまとめた専用ページがあります。

## WooCommerce ショップ向け

- **[Sawir Renew](https://sawirstudio.com/ja/projects/wordpress-plugins/sawir-renew/)。** WooCommerce 向けのサブスクリプション機能です。定期課金、トライアル、初期費用、一時停止とスキップ、プラン変更、支払い失敗時の督促とスマートな再試行まで、すべて無料でお使いいただけます。
- **[Sawir Referral](https://sawirstudio.com/ja/projects/wordpress-plugins/sawir-referral/)。** 紹介する側とされる側の両方に特典がある紹介プログラムです。ご友人には割引、紹介した方にはリワードクーポンを提供し、コードやリンクで共有できます。WhatsApp での共有を最優先に考えています。
- **[Sawir Pulse](https://sawirstudio.com/ja/projects/wordpress-plugins/sawir-pulse/)。** 実際の動きだけを使ったソーシャルプルーフです。最近の注文、閲覧中のユーザー数、レビューを、画面の隅に小さな通知として表示します。
- **[Sawir Restock Notifier](https://sawirstudio.com/ja/projects/wordpress-plugins/sawir-restock-notifier-for-woocommerce/)。** 在庫切れの商品が再入荷したときに、お客様がメールで通知を受け取れるよう申し込めます。
- **[Sawir Min Max Quantities](https://sawirstudio.com/ja/projects/wordpress-plugins/sawir-min-max-quantities-for-woocommerce/)。** 商品ごと、カテゴリーごと、注文全体に対して、最小数量と最大数量のルールを設定できます。
- **[Sawir Product Image Zoom](https://sawirstudio.com/ja/projects/wordpress-plugins/sawir-product-image-zoom-for-woocommerce/)。** 商品ギャラリー用のライトボックスです。画像の切り替えやクリックでの拡大に対応しています。
- **[Sawir Variation Gallery Tools](https://sawirstudio.com/ja/projects/wordpress-plugins/sawir-variation-gallery-tools-woocommerce/)。** 商品のバリエーションごとにギャラリー画像を設定できます。Product Image Zoom と組み合わせてお使いいただけます。

## あらゆる WordPress サイト向け

- **[Sawir Insights](https://sawirstudio.com/ja/projects/wordpress-plugins/sawir-insights/)。** ヒートマップ、セッション録画、アンケート、ファネル、フォーム分析を提供します。データはすべてお客様ご自身のサーバーに保存されます。
- **[Sawir Social Scheduler](https://sawirstudio.com/ja/projects/wordpress-plugins/sawir-social-scheduler/)。** 一度書くだけで、wp-admin から 27 のネットワークに投稿を予約できます。チャンネルごとの編集、スレッド、メディア、プレビューにも対応しています。
- **[Sawir Live Translate](https://sawirstudio.com/ja/projects/wordpress-plugins/sawir-live-translate/)。** フロントエンドのあらゆるページをその場で翻訳し、翻訳文を保存して、訪問者が言語を切り替えられるようにします。
- **[Sawir Media Folders](https://sawirstudio.com/ja/projects/wordpress-plugins/sawir-media-folders/)。** メディアライブラリに、高速で数の制限がないフォルダーを作成できます。ドラッグ＆ドロップで操作できます。
- **[Sawir Role Capabilities Manager](https://sawirstudio.com/ja/projects/wordpress-plugins/sawir-role-capabilities-manager/)。** 独自のユーザー権限グループ（ロール）を作成し、各ロールにできる操作を管理できます。

## 進め方

プラグインは他社のビジネスの中で動くものなので、私たちはいくつかのルールを自らに課しています。どのプラグインも WordPress.org で無料で公開しており、役割は一つに絞っています。データはサイト運営者のサーバーに残ります。Insights は外部サービスを使わずにセッションを記録し、Social Scheduler はトークンを WordPress 内に保管します。そして、見せかけはしません。Pulse は実際に起きた動きだけを表示し、Renew は他社が有料にしているサブスクリプション機能を無料で提供しています。

**使用技術** PHP、WordPress、WooCommerce

- **プラグイン** 12 個（無料）
