# Sawir Restock Notifier

![Sawir Restock Notifier のバナー](https://sawirstudio.com/assets/images/plugins/sawir-restock-notifier-for-woocommerce-banner.webp)

Sawir Restock Notifier は、在庫切れの商品ページでお客様にメールアドレスを登録していただき、再入荷したときに一度だけお知らせするプラグインです。

[WordPress.org で無料入手](https://wordpress.org/plugins/sawir-restock-notifier-for-woocommerce/)

## 主な機能

Sawir Restock Notifier for WooCommerce は、在庫切れの商品ページに軽量な在庫通知フォームを追加します。お客様がメールアドレスを入力し、メールで申し込みを確認すると、商品または選択したバリエーションが再入荷した際に、一度だけメールが届きます。

## 主な機能

- 在庫切れ商品の在庫通知欄に、再入荷通知フォームを表示します。
- 単一商品とバリエーション商品に対応しています。
- ゲストのお客様とログイン中のお客様の両方に対応しています。
- 再入荷通知の登録前にログインを必須にする設定を、任意で利用できます。
- ダブルオプトインによる確認を行ってから、再入荷通知を有効にします。
- お客様宛てのメールに、キャンセルと配信停止のリンクを記載します。
- 管理者は、未確認のリクエストに対して確認メールを再送できます。
- 「マイアカウント > 再入荷通知」ページを追加します。ログイン中に作成した通知については、お客様がここで確認、キャンセル、配信停止、確認メールの再送を行えます。
- 確認待ち、確認済み、通知済み、配信停止のリクエストを、専用のデータベーステーブルに保存します。
- 在庫ステータスが「在庫あり」に戻ると、WooCommerce のデザインに沿った再入荷メールを送信します。
- WooCommerce Action Scheduler を使い、再入荷通知メールをバックグラウンドでバッチ処理します。
- リクエストを確認できる「WooCommerce > 再入荷通知」管理ページを追加します。
- 期間フィルター、ステータス別の合計、各種の比率、リクエストの多い商品を確認できる、管理者向けのインサイトダッシュボードを表示します。
- プラグインを削除する際にプラグインのデータも消去する、アンインストール時のクリーンアップ設定を任意で利用できます。
- プラグインの停止時に、後でプラグインを削除した場合、データを残すか完全に削除するかを管理者に確認します。

## よくある質問

### 他の選択肢と比べてどうですか？

YITH WooCommerce Waiting List や有料の再入荷通知拡張機能のようなウェイトリスト系のスイートには、ダッシュボード、エクスポート可能なウェイトリスト、SMS、マーケティング連携などの機能があります。Sawir Restock Notifier は、必要な流れだけに絞っています。在庫切れ商品に設置する小さなフォーム、ダブルオプトインによる確認、そして商品またはバリエーションが戻ったときの一通のメールです。ウェイトリストを使ってマーケティングを行う予定がある場合はスイートをお選びください。在庫切れのページからお客様が離れてしまうのを防ぎたいだけであれば、このプラグインがまさにその役目を果たします。

### WooCommerce は必須ですか？

はい。このプラグインは、WooCommerce の商品と在庫ステータスのフックに対応して作られています。

### お客様に複数回通知が届くことはありますか？

いいえ。再入荷メールを送信すると、各リクエストは「通知済み」になります。

### ダブルオプトインに対応していますか？

はい。お客様が確認用のリンクをクリックするまで、再入荷通知は有効になりません。
