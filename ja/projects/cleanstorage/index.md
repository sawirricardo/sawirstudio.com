# CleanStorage

iPhoneの容量を使っているものを見つけて、残すかどうかを決められます

CleanStorageは、iPhoneの容量を使っているものを見つけて、残すかどうかを決めるためのアプリです。広告もサブスクリプションもなく、1日の利用制限もありません。
