# Squishu

餃子をぷにぷにつぶして、蒸気が切れる前にボスを倒そう。

Squishuは、食べ物をつぶして遊ぶかわいいクリッカーゲームです。餃子、おにぎり、お寿司、お餅、タピオカなどをタップして弾けさせ、各ワールドのボスをタイマーが切れる前に倒しましょう。餃子の仲間たちを雇えば、留守の間もつぶし続けてくれて、戻ってくるとせいろいっぱいのコインが待っています。
