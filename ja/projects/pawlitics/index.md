# Pawlitics

動物たちの町がすべての政策に反応する、ほのぼのカートゥーン政治シム

ブランブルウッドには知事が必要です。あなたが務めますか?

Pawlitics は、ほのぼのとしたカートゥーン調の政治シミュレーションゲームです。知事を選び、政策を決めると、動物だらけの町がそれぞれに反応します。ヘルメット姿のクマ、蝶ネクタイのニワトリ、靴箱に暮らして「意外と快適なんだよ」と言うネズミたち。
