Sawir Role Capabilities Manager

Sawir Role Capabilities Manager lets you create your own user roles and decide exactly what each role, new or built in, can do.

Get it free on WordPress.org

What it does

Sawir Role Capabilities Manager adds an admin-only role capabilities screen under Users. Administrators can create roles, copy capabilities from existing roles, add custom capability keys, and manage capabilities on existing roles.

Questions

How does it compare to alternatives?

User Role Editor, Members, and PublishPress Capabilities are the established tools here, with pro tiers adding content restriction, front-end protection, and admin-menu control. Sawir Role Capabilities Manager covers the core administrative task in one screen under Users, free: create roles, copy capabilities between roles, add custom capability keys, and edit existing roles. If you need to restrict content or build membership levels, reach for Members or PublishPress; if you need clean role and capability management, this is enough.
