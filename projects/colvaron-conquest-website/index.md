# Colvaron Conquest Website

![Colvaron Conquest home page](https://sawirstudio.com/assets/images/projects/colvaron-conquest-website.webp)

## The client

Colvaron Conquest is a strategic trading card game created by Coco JM. Its world, where magic and advanced technology collide, began in Coco’s childhood imagination and became a card game in 2025, played with five elements and a two-dice action system.

## What we made

We designed and built the game’s website, where players discover the cards, learn the world and learn to play.

- **Card gallery.** More than 200 cards that players can search, sort and filter by element, faction and type.
- **A page for every card,** so each one can be found, linked and shared on its own.
- **Lore.** Fifteen stories of Colvaron: how the five elements were born, the continent, its kingdoms and factions.
- **Tutorials.** How-to-play rules with the element chart, for players picking up the game for the first time.
- **News.** Updates from the team as the game grows.
- **A simple CMS.** The team publishes lore and news themselves, and every change is saved to the site’s Git history.

## How we approached it

A trading card game sells on its art, so the site gets out of the way: dark pages, large card art and filters that answer straight away. Behind it, the site is built for search. Titles and descriptions target the phrases card players search for, every page is in a full sitemap, and since Facebook, X and WhatsApp can’t show the site’s AVIF images, the build makes a JPEG share image for every page.

**Built with** Astro, Tailwind CSS and Cloudflare Pages
