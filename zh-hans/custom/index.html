新增：定制软件

量身打造，贴合您的业务的软件。

现成的工具总要您按它的方式做事，我们则打造按您的方式运转的软件：面向客户或员工的应用、办公室使用的系统，以及支撑它们的管理后台。全部归您所有。

开始项目 定制值得吗？

我们的业务

  • 支撑办公室运转的系统

    把维系您业务的各种电子表格和聊天群，整合成一个系统：订单、审批、排班、人事、发票，以及您真正会看的报表。

  • 印有您品牌的应用

    面向客户、会员或外勤员工的 iPhone 和 Android 应用，以您的名义发布，从第一个版本到之后的每次更新。

  • 交易平台与门户

    客户、商家、会员或合作伙伴登录并办理事务的平台，每个人只能看到属于自己的内容，您的团队则通过管理后台来运营。

  • 支付、物流及其他

    我们已经集成过的支付网关：Sawir Renew 中用于定期扣款的 Stripe，Kantong Sayur 中的 Midtrans，Koperasi HOB 中的 iPaymu，以及我们的 Odoo 连接器中的 Shopify Payments 结算。此外还有按地区定价的配送，以及与 Odoo、Shopify 和您已在付费使用的各类工具的对接。

  • 为 AI 助手做好准备

    为 ChatGPT、Claude 等助手提供安全的方式，按每位用户各自的权限读取您的系统并执行操作，就像我们为 SawirPost 打造的 MCP 服务器一样。

  • 多年持续维护

    包括托管、安全更新、应用商店的新规则，以及您清单上的下一个功能。我们会一直陪伴自己做出来的产品：PeopleBond 自 2019 年起一直与我们合作。

定制值得吗？

定制的前期投入比订阅更高，所以必须物有所值。出现以下情况时，通常就值得：

  • 您的做事方式就是您的优势。比如竞争对手没有的定价模式、服务或流程，通用工具只会把它们抹平。
  • 您在为四个工具付费，还要靠电子表格把它们拼在一起。一个完全贴合您工作的系统，往往在两年左右就能省下更多成本。
  • 您的客户需要的是您自己的应用，而不是通向别人平台的链接。

如果现成的标准工具已经能胜任，就不必定制，我们也会如实相告。如果您需要的是收银、库存和会计，请先从 Odoo 入手，只定制它缺少的部分。

合作流程

  1. 从小处着手，尽早上线。

    我们先挑出最重要的一个环节，尽早把可用的版本交到您的真实用户手中，再根据他们的实际使用情况不断完善。

  2. 看着它一步步成长。

    您在开发过程中就能使用，而不是等到最后。AI 承担了大量的编码工作，所以我们速度很快；而每一行代码，都有专人审阅、测试并负责。

  3. 上线只是开始。

    上线之后，我们会继续留下来修复、更新和扩充，只要您需要，就一直陪着您。

哪些归您所有

代码、数据和账号，全部以您的名义持有。一切都基于开放、主流的工具构建，任何优秀的开发者都能接手。我们希望您留下来，是因为我们的工作做得好，而不是因为您无法离开。

Ricardo Sawir，创始人

我们做过的定制项目

  • Koperasi HOB：一家合作社的完整商店，包含会员应用、分店库存、通过 iPaymu 支付，以及用于运营的管理后台。
  • Kantong Sayur：面向传统市场的交易平台，包含买家和商家两端的应用、Midtrans 支付、批发价目表，以及可从管理后台打印的发票。
  • PeopleBond：涵盖招聘到薪资的人力资源平台，以及用于考勤和审批的员工应用，自 2019 年起与他们的团队共同打造。
  • TaniMilenial：面向农户的 Android 应用，包含农事记录、市场价格和农资商店。
  • DBTV：为某教会机构的会众提供讲道、祷告和每日灵修内容的 iOS 和 Android 应用。
  • SawirPost：我们自己开发的面向代理机构的社交媒体排期工具，带有供 AI 助手使用的 MCP 服务器。
