新增：Odoo 与业务系统

从收银台到账本，一套系统搞定。

收银、库存、采购和会计，都在同一个地方。如果 Odoo 适合您的工作方式，就用 Odoo；不适合，就为您量身定制。在您花钱之前，我们会先告诉您该选哪一种。

开始项目 用 Odoo 还是定制？

我们能做什么

  • 为您配置好 Odoo

    收银、库存、采购、销售和会计，都按照您现有的业务流程来配置，而不是让您去迁就系统。我们为 Odoo 编写模块，对它的内部机制非常了解。

  • 所有门店，同一份库存

    每家门店和仓库共用同一份库存，支持按尺码和颜色设置变体、条码、门店之间调拨，还有补货提醒，在缺货之前就会通知您。

  • 线上销售，同一份库存

    您的 Shopify 店铺通过我们编写的开源连接器接入，您的网站或其他渠道则通过各自的 API 接入，这样您就不会卖出已经没有的货。

  • 量身定制

    如果您的与众不同之处正在于工作方式，我们就围绕它来搭建系统：供办公室使用的网页应用、供员工或客户使用的应用，以及它们背后的管理后台。代码和数据都归您所有。详见定制软件。

  • Odoo 加上您自己的部分

    很多时候，Odoo 能覆盖几乎所有需求，只有一部分工作需要专属的功能。我们保留 Odoo 作为核心，再为您开发它所缺少的那一个模块、应用或报表。

  • 上线迁移

    把产品、客户、供应商、期初库存和余额，从电子表格或旧软件中迁移过来，并在正式上线前培训好收银台的同事。

用 Odoo 还是定制？

这是每个人最先问的问题，而老实的答案取决于您的业务到底有多特殊。

  • 如果您的流程和大多数商店、经销商和餐厅一样：销售、补货、付款给供应商、月末结账，就选 Odoo。它更快、更便宜，而且是开源的，Odoo 社区版不收许可费。您需要稍微调整自己的做法来适应它。
  • 如果系统本身就是业务，比如定价模型、审批链，或是 Odoo 每一步都会不匹配的服务，就选量身定制。前期成本更高，但完全贴合。
  • 如果 Odoo 能覆盖日常工作，而您有一部分工作是独一无二的，就两者结合。这是最常见的答案。

我们会先梳理您的流程，然后以书面形式给出推荐，并附上每种方案的费用。无论您选哪一种，系统都建立在开放、主流的工具之上，任何优秀的开发者都能接手，所以您不会被我们绑定。

合作流程

  1. 先到现场看一看。

    我们会按照目前的实际情况，跟踪一笔销售、一次发货、一次盘点和一次月末结账，并记下哪里容易出问题。

  2. 一次做一部分。

    通常先做收银和库存，再做采购，最后做会计。每一部分都先用您的真实数据跑通，再开始下一部分，所以店铺不会停业。

  3. 我们会一直在。

    新门店、新报表、Odoo 版本升级，以及忙碌的周六冒出来的各种问题。PeopleBond 自 2019 年起就一直与我们合作。

我们不会做的事

向您推销您不需要的系统。如果 Odoo 的标准应用已经够用，我们会直说，不做多余的定制。如果您的流程确实不同，我们也不会为了自己省事，硬把它塞进 Odoo。

Ricardo Sawir，创始人
