# Pawlitics

一款温馨的卡通政治模拟游戏，小镇上的动物会对每项政策做出反应

Bramblewood 需要一位州长，会是您吗？

Pawlitics 是一款温馨的卡通政治模拟游戏。选出州长，制定政策，看看满镇的动物如何反应：戴着安全帽的熊、系着领结的鸡，还有住在鞋盒里、还说“其实挺不错”的老鼠。
