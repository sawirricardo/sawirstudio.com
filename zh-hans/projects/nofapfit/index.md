# NoFapFit

冲动来袭时的即时运动挑战，用连续打卡培养自律

NoFapFit 把冲动变成一次锻炼。当诱惑出现时，您只需按下一个醒目的红色大按钮，就会随机得到一项带有固定次数的运动：俯卧撑、深蹲、波比跳或平板支撑。这股能量会用在锻炼身体上，而不是变成内疚。

您完成的每一次挑战都会累积到连续打卡天数中，每周视图会显示您的训练次数和最常做的运动，还有最长连续打卡排行榜。Iron Will Pro 可解锁全部 16 种运动、卧推、硬拉和壶铃摆荡等负重训练，以及更深入的统计数据。
