# Sawir Variation Gallery Tools

![Sawir Variation Gallery Tools 横幅图](https://sawirstudio.com/assets/images/plugins/sawir-variation-gallery-tools-woocommerce-banner.webp)

Sawir Variation Gallery Tools 让每个商品变体都拥有自己的图库，选择红色款时，显示的就是红色款的照片。它与 Sawir Product Image Zoom 配合使用，效果更佳。

[在 WordPress.org 免费获取](https://wordpress.org/plugins/sawir-variation-gallery-tools-woocommerce/)

## 功能介绍

Sawir Variation Gallery Tools for WooCommerce 会在 WooCommerce 商品编辑器中为每个变体添加一个“变体附加图片”字段。

当顾客在商品页面选择某个变体时，该变体已保存的图片会被添加到 WooCommerce 商品图库中。

店铺管理员还可以在 WooCommerce > Variation Images 中批量导出和导入变体附加图片。CSV 导出文件包含每个变体的 ID、SKU、属性、附加图片 ID 和图片 URL。CSV 导入时，可以替换或追加所导入行对应的图片。

本插件可与 Sawir Product Image Zoom for WooCommerce 配合使用：https://wordpress.org/plugins/sawir-product-image-zoom-for-woocommerce/

变体图片会作为标准的 WooCommerce 图库图片添加，因此 Sawir Product Image Zoom for WooCommerce 可以将它们纳入其灯箱和缩放体验中。

## 常见问题

### 与其他方案相比如何？

Additional Variation Images Gallery 和 Iconic WooThumbs 等插件，会把变体图片与它们自带的图库播放器（轮播、布局、视频）搭配在一起。Sawir Variation Gallery Tools 则只负责保存每个变体的图片，并将其送入标准的 WooCommerce 图库，因此您的主题和配套插件（例如 Sawir Product Image Zoom）无需改动即可照常运行，店铺管理员还能通过 CSV 导出/导入批量编辑。如果您想要全新的图库体验，请选用功能套件；如果您只想在现有图库中显示变体图片，这款专注的插件正适合您。

### 它能与 Sawir Product Image Zoom for WooCommerce 配合使用吗？

可以。本插件添加的变体图片使用标准的 WooCommerce 商品图库标记，因此可以与 Sawir Product Image Zoom for WooCommerce 配合使用。

### 我可以批量更新、导出或导入变体图片吗？

可以。前往 WooCommerce > Variation Images，即可导出 CSV，或导入按 `variation_id` 或 `variation_sku` 匹配变体的 CSV。导入的行可以使用媒体库中已有的附件 ID 或 URL。
