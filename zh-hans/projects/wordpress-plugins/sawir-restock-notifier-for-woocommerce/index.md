# Sawir Restock Notifier

![Sawir Restock Notifier 横幅图](https://sawirstudio.com/assets/images/plugins/sawir-restock-notifier-for-woocommerce-banner.webp)

Sawir Restock Notifier 让顾客在缺货商品页面留下邮箱，商品恢复库存后，只会通知他们一次。

[在 WordPress.org 免费获取](https://wordpress.org/plugins/sawir-restock-notifier-for-woocommerce/)

## 功能介绍

Sawir Restock Notifier for WooCommerce 为缺货商品页面添加一个轻量的到货提醒表单。顾客填写邮箱地址，并通过邮件确认请求，之后当商品或所选变体恢复库存时，会收到一封一次性的邮件通知。

## 功能特点

- 在缺货商品的库存提示处显示到货通知表单。
- 支持简单商品和商品变体。
- 同时支持访客和已登录的顾客。
- 提供可选设置，可要求顾客登录后才能订阅到货提醒。
- 采用双重确认（double opt-in）机制，确认后到货提醒才会生效。
- 发给顾客的邮件中附有取消和退订链接。
- 管理员可以为未确认的请求重新发送验证邮件。
- 新增“我的账户 > 到货提醒”页面，已登录的顾客可以查看、取消、退订在登录状态下创建的提醒，也可以重新发送验证邮件。
- 将待确认、已确认、已通知和已退订的请求存储在自定义数据库表中。
- 当库存状态变回有货时，发送 WooCommerce 风格的到货通知邮件。
- 通过 WooCommerce Action Scheduler 在后台分批处理到货通知邮件。
- 新增 WooCommerce > Restock Alerts 管理页面，用于查看各项请求。
- 在后台提供数据洞察面板，包含时间范围筛选、各状态总数、比率以及最受关注的商品。
- 提供可选的卸载清理设置，可在删除插件时一并清除插件数据。
- 停用插件时会询问管理员：如果之后删除插件，是保留插件数据，还是彻底清除。

## 常见问题

### 与其他方案相比如何？

YITH WooCommerce Waiting List 这类候补名单套件，以及各种商业版到货通知扩展，提供数据面板、可导出的候补名单、短信和营销集成等功能。Sawir Restock Notifier 只专注于最核心的流程：在缺货商品上放一个小表单，进行双重确认，商品或变体恢复库存后发送一封邮件。如果您打算向候补名单中的顾客做营销，请选择功能更全的套件；如果您只是不想让顾客在缺货页面直接离开，这款插件正好能做到。

### 这个插件需要 WooCommerce 吗？

是的。这款插件专为 WooCommerce 商品和库存状态钩子而构建。

### 会多次通知顾客吗？

不会。到货通知邮件发出后，每条请求都会被标记为已通知。

### 支持双重确认吗？

支持。顾客必须点击确认链接，到货提醒才会生效。
