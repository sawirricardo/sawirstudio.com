# Sawir Role Capabilities Manager

![Sawir Role Capabilities Manager 横幅图](https://sawirstudio.com/assets/images/plugins/sawir-role-capabilities-manager-banner.webp)

Sawir Role Capabilities Manager 让您创建自己的用户角色，并精确决定每个角色（无论是新建的还是内置的）能做什么。

[在 WordPress.org 免费获取](https://wordpress.org/plugins/sawir-role-capabilities-manager/)

## 功能介绍

Sawir Role Capabilities Manager 在“用户”菜单下新增一个仅限管理员使用的角色权限页面。管理员可以创建角色、从现有角色复制权限、添加自定义权限键，并管理现有角色的权限。

## 常见问题

### 与其他方案相比如何？

User Role Editor、Members 和 PublishPress Capabilities 是这一领域的成熟工具，其专业版还提供内容限制、前台保护和后台菜单控制等功能。Sawir Role Capabilities Manager 把核心的管理任务集中在“用户”菜单下的一个页面里，而且免费：创建角色、在角色之间复制权限、添加自定义权限键，以及编辑现有角色。如果您需要限制内容或搭建会员等级，请选择 Members 或 PublishPress；如果您只需要干净利落的角色与权限管理，用它就够了。
