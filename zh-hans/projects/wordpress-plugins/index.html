WordPress 插件

项目简介

WordPress 支撑着网络上相当大的一部分网站，而 WooCommerce 则支撑着其中许多网店。我们在 WordPress.org 上发布面向两者的免费插件，每个插件只把一件事做好，这样站长可以按需添加，不必为用不上的功能买下一整套。下面每个插件都有独立的页面，介绍其功能并解答常见问题。

适用于 WooCommerce 网店

  • Sawir Renew。WooCommerce 订阅插件：定期扣款、试用、注册费、暂停与跳过、方案切换、催款和智能重试，全部免费。
  • Sawir Referral。双向受益的推荐计划：被推荐的朋友享受折扣，推荐人获得奖励优惠券，可通过优惠码或链接分享，优先支持 WhatsApp。
  • Sawir Pulse。只展示真实动态的社交证明：最新订单、实时浏览人数和评价，以角落小通知的形式呈现。
  • Sawir Restock Notifier。顾客可以申请，在缺货商品重新到货时收到邮件通知。
  • Sawir Min Max Quantities。可按商品、按分类以及针对整个订单设置最小和最大购买数量规则。
  • Sawir Product Image Zoom。为商品图库提供灯箱效果，支持切换浏览和点击放大。
  • Sawir Variation Gallery Tools。为每个商品变体设置独立的图库图片，可与 Product Image Zoom 配合使用。

适用于任何 WordPress 网站

  • Sawir Insights。热力图、会话录制、问卷调查、转化漏斗和表单分析，所有数据都保存在您自己的服务器上。
  • Sawir Social Scheduler。写一次内容，直接在 wp-admin 中定时发布到 27 个社交网络，支持分渠道编辑、串文、媒体和预览。
  • Sawir Live Translate。实时翻译任意前台页面，保存翻译字符串，并让访客自行切换语言。
  • Sawir Media Folders。为媒体库提供快速、数量不限的文件夹，支持拖放操作。
  • Sawir Role Capabilities Manager。创建自定义用户角色，并管理每个角色可执行的操作。

我们的做法

插件运行在别人的生意之中，所以我们给自己定了几条规矩。每个插件都在 WordPress.org 上免费提供，并且只做一件事。数据留在站长自己的服务器上：Insights 无需第三方服务即可记录会话，Social Scheduler 把令牌保存在 WordPress 中。同时绝不弄虚作假：Pulse 只展示真实发生过的动态，Renew 则免费提供其他插件收费的订阅功能。
