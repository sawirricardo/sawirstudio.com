# Sawir Product Image Zoom

![Sawir Product Image Zoom 横幅图](https://sawirstudio.com/assets/images/plugins/sawir-product-image-zoom-for-woocommerce-banner.webp)

Sawir Product Image Zoom 可在灯箱中打开您的商品图片，通过箭头切换图库中的图片，点击即可放大查看细节。

[在 WordPress.org 免费获取](https://wordpress.org/plugins/sawir-product-image-zoom-for-woocommerce/)

## 功能介绍

Sawir Product Image Zoom for WooCommerce 用专注的灯箱体验，取代 WooCommerce 商品图库默认的图片点击行为。

功能特点：

- 在全屏灯箱中打开商品图片。
- 支持上一张、下一张切换。
- 支持键盘操作：Esc 键、左方向键和右方向键。
- 支持触屏设备上的滑动切换。
- 支持点击放大，放大后可拖动平移。
- 兼容经典 WooCommerce 商品图库和区块式商品图库。

插件只在单个商品页面加载其 CSS 和 JavaScript。

## 常见问题

### 与其他方案相比如何？

Iconic WooThumbs 和 YITH Zoom Magnifier 这类图库套件，会替换整个 WooCommerce 商品图库，包括布局、滑块、视频和放大功能。Sawir Product Image Zoom 只改变一件事：顾客点击图片时会发生什么。您主题自带的图库保持原样，顾客则能获得快速的灯箱体验，支持键盘操作、滑动切换和点击放大，而且资源只在商品页面加载。如果您想重新设计图库本身，请选择图库套件；如果图库本身没问题，只是查看体验不够好，这款插件是更轻量的选择。

### 这个插件需要 WooCommerce 吗？

需要。这款插件是为 WooCommerce 商品图库打造的。

### 会在整个网站加载资源吗？

不会。资源只在 WooCommerce 单个商品页面加载。

### 支持触屏设备吗？

支持。灯箱在触屏设备上支持滑动切换，以及放大后的图片平移。
