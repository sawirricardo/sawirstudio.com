Sawir Media Folders

Sawir Media Folders 为 WordPress 媒体库带来文件夹功能，数量不限，拖放即可整理文件。

在 WordPress.org 免费获取

功能介绍

将媒体库整理成文件夹和子文件夹。不限文件夹数量，没有付费升级的套路。

  • 文件夹和子文件夹数量不限——没有上限。
  • 快速——无论媒体库有多大，整个文件夹树只需两次数据库查询即可加载。筛选使用 WordPress 原生的媒体查询。
  • 安全——文件夹是虚拟的（一种分类法）。实际文件不会移动，所以链接不会失效。删除文件夹也不会删除文件。

常见问题

与其他方案相比如何？

FileBird、HappyFiles 和 Real Media Library 都是成熟的文件夹插件，附带不少精致的扩展功能，但它们的免费版通常会限制可创建的文件夹数量。Sawir Media Folders 把功能范围控制得很精简：虚拟文件夹、拖放、快速筛选，没有数量上限，也没有付费版。文件夹是一种分类法，因此文件不会被实际移动，任何链接都不会失效。如果您需要按用户划分文件夹或图库集成等额外功能，付费方案物有所值；如果您只是想把媒体库整理好，这款插件免费又快速。

文件夹会改变我的文件链接吗？

不会。文件夹只用于整理（附件上的一种隐藏分类法）。文件仍保留在 WordPress 上传时的位置。

停用或删除插件会怎么样？

不会有任何问题。您的文件不受影响，文件夹归属只是不再显示。重新启用后，它们就会恢复。

免费版有文件夹数量限制吗？

没有付费版。所有功能都免费，且不限数量。
