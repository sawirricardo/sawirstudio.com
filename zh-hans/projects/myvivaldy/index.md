# MyVivaldy

![MyVivaldy 应用界面：预约就诊、就诊记录和账户](https://sawirstudio.com/assets/images/projects/myvivaldy.webp)

## 客户

Vivaldy Skin Clinic 是一家皮肤与性病专科诊所，由 PT Viva Estemedika Indonesia 运营。我们还为其开发了[网站](https://sawirstudio.com/zh-hans/projects/vivaldy-skin-clinic-website/)，并制作了[营销设计](https://sawirstudio.com/zh-hans/projects/vivaldy-skin-clinic-marketing-design/)。

## 我们做了什么

MyVivaldy 包含两部分：诊所日常运营所用的系统，以及患者随身携带的应用。

诊所端系统负责一整天的运转，从预约、临床病历到药房，都在其中。

患者应用，支持 iPhone 和 Android：

- **预约。** 选择诊所、问诊或治疗项目、医生、日期和时间。只会显示医生确实有空的时间。
- **提醒。** 下一次预约会显示在首页，并会在就诊前发送推送通知。
- **就诊记录。** 查看过往就诊记录，包括接受过的治疗和开具的药品。
- **账户。** 可使用电子邮箱或手机号码登录，支持英语和印尼语，也可以直接在应用内删除账户。

## 我们的做法

两端共用同一套系统。患者在应用中看到的可约时间，来自诊所自己维护的排班表；医生记录的就诊信息，也会出现在患者的就诊记录里。应用为原生开发，iPhone 端使用 SwiftUI，Android 端使用 Jetpack Compose，并通过 API 与诊所系统通信。自 2024 年起，我们一直在为 MyVivaldy 工作。

**技术栈** Laravel、Filament、PostgreSQL、SwiftUI 和 Jetpack Compose
