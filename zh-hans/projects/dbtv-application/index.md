# DBTV 应用

Ps. Debby Basjir 的讲道、祷告与每日灵修

![DBTV 应用横幅](https://sawirstudio.com/assets/images/projects/dbtv-application.webp)

## 客户

DBTV 是 Ps. Debby Basjir 事工的媒体频道，为在线上跟随事工的会众提供讲道、祷告聚会、敬拜和灵修内容。

## 我们做了什么

我们为 DBTV 开发了 iOS 和 Android 应用，让会众用手机就能跟随事工。

- **讲道与敬拜。** 独家讲道视频、赞美敬拜和播客，视频可直接在应用内播放。
- **祷告。** 在线祷告聚会，包括儿童的 Mezbah Doa。
- **每日灵修。** 每天更新一篇灵修文章，排版清晰，便于阅读。
- **活动。** 浏览即将举行的活动、在线报名，并查看您已报名的所有人。
- **商店。** DBTV 周边商品，链接到其 Tokopedia 和 Shopee 店铺。
- **DBTV+。** 会员服务，可抢先观看独家内容。
- **通知。** 有新内容发布时，会推送通知给您。

## 我们的做法

事工每天都会发布新内容，所以应用没有把这些内容写死：灵修、讲道和活动都来自 DBTV 的平台，无需更新应用就会显示。当应用本身有变化时，会提示用户更新，这样所有会众都使用同一个版本，不会有人被旧版本的问题困扰。

**技术栈** Expo (React Native)
