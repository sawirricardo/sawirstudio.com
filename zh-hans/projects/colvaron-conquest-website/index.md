# Colvaron Conquest 网站

![Colvaron Conquest 首页](https://sawirstudio.com/assets/images/projects/colvaron-conquest-website.webp)

## 客户

Colvaron Conquest 是由 Coco JM 创作的策略类集换式卡牌游戏。游戏的世界中，魔法与先进科技交汇，最初源于 Coco 童年时的想象，并于 2025 年成为一款卡牌游戏，玩法围绕五种元素和双骰行动系统展开。

## 我们做了什么

我们设计并搭建了这款游戏的网站，玩家可以在这里浏览卡牌、了解世界观、学习玩法。

- **卡牌图鉴。** 200 多张卡牌，玩家可以按元素、阵营和类型搜索、排序和筛选。
- **每张卡牌都有独立页面，** 方便单独查找、链接和分享。
- **世界观。** 十五个关于 Colvaron 的故事：五种元素如何诞生、大陆的样貌，以及各个王国和阵营。
- **教程。** 附有元素相克图的玩法规则，适合初次接触这款游戏的玩家。
- **新闻。** 团队随游戏成长发布的最新动态。
- **简单易用的 CMS。** 团队可以自行发布世界观故事和新闻，每次修改都会保存到网站的 Git 历史记录中。

## 我们的做法

集换式卡牌游戏靠卡面美术吸引玩家，所以网站尽量不抢画面：深色页面、大幅卡牌图片，以及即时响应的筛选功能。在背后，网站针对搜索做了优化。标题和描述瞄准卡牌玩家会搜索的词句，每个页面都收录在完整的站点地图中；由于 Facebook、X 和 WhatsApp 无法显示网站使用的 AVIF 图片，构建时还会为每个页面生成一张 JPEG 分享图。

**技术栈** Astro、Tailwind CSS 和 Cloudflare Pages
