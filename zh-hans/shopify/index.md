# Shopify，账目清楚。

订单、库存、结算款和门店收银（POS），在您的 Shopify 店铺与 Odoo 或其他系统之间顺畅流转。由编写 Shopify 开源 Odoo 连接器的团队打造，让账目对得上。

[开始项目](https://sawirstudio.com/zh-hans/contact/) [了解连接器](https://sawirstudio.com/zh-hans/projects/odoo-shopify-connector/)

## 我们能做什么

- ### Shopify 与 Odoo

  通过我们编写的 [OCA 连接器](https://sawirstudio.com/zh-hans/projects/odoo-shopify-connector/)，将您的店铺与 Odoo 19 Community 连接起来：商品、库存、客户、订单、退货与退款，单店或多店均可。我们负责安装部署，按您的工作方式配置，并在您的业务需要更多功能时进行扩展。还没有使用 Odoo？我们也可以[帮您搭建](https://sawirstudio.com/zh-hans/odoo/)。
- ### 账目对得上

  Shopify Payments 的结算款、手续费、争议款项、礼品卡和多币种，都按 Shopify 的精确金额生成会计分录。如果数字对不上，您会看到明确的错误提示，而不是一条悄悄平账的分录。
- ### 门店收银与仓库

  各门店的 Shopify POS 销售会作为订单导入，并分配到对应的 Odoo 仓库，让您在每个销售渠道的库存都准确无误。
- ### 您的其他系统

  没有使用 Odoo？我们可以通过 GraphQL Admin API 和签名 webhook，把 Shopify 连接到您现有的 ERP、财务软件、物流系统或自建后台，并通过校验机制找出任何遗漏。
- ### 定制应用与自动化

  针对 Shopify 默认不支持的需求，我们可以开发私有应用或定时任务，例如订单分配、批量编辑、自定义报表，以及与供应商的数据同步。
- ### 店铺也可以交给我们

  如果店铺前台需要搭建或改版，我们可以在做集成的同时一并设计和开发，让前端与后端统一规划。

## 合作流程

1. ### 先梳理清楚。

   我们会列出每一条流程：哪些数据要流转、流向哪里，以及库存、价格和资金以哪个系统为准。
2. ### 一次做一条流程。

   通常先做订单和库存，再做财务，最后是门店收银。每一项都会先用您的真实数据跑通，再开始下一项。
3. ### 长期稳定运行。

   健康检查、同步看板和定时对账，再加上我们的持续支持。Shopify 调整 API 时，我们会继续负责维护。

我们不会做的

只在大多数时候正确的集成。对库存和资金来说，这就是错的。我们做的集成从不假定 webhook 一定送达，会定时与 Shopify 自行核对，并在数字不一致时暂停并通知您。
