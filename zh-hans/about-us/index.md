# 很高兴您找到了我们

一家交付迅速的工作室：AI 参与其中，每个决定都由人来负责。

创始人的话

我创办 SawirStudio，是想打造真正经得起用户使用的应用、网站和设计。如今，我们每天都在借助 AI 开发。它负责写出大量初稿，SawirStudio 也因此在不到四周的时间里，把自家的六款应用上架到了 App Store。

不过，工具无法为决定负责，所以由我们来负责。我们会阅读代码，在真机上测试，并对上线的每一处内容负责。客户项目同样如此。

[Ricardo Sawir](https://sawirstudio.com/zh-hans/ricardosawir/)，创始人

## 我们的理念

1. ### 先上线，再打磨。

   与其闭门反复打磨，我们更愿意尽早把真实的产品交到用户面前。我们自家的六款应用，从想法到上架 App Store，都用了不到四周。
2. ### AI 负责敲代码，我们负责思考。

   我们每天都在借助 AI 开发。这让我们速度更快，费用也比您预想的更低。但每一行上线的代码，仍然有人逐行阅读、测试并负责。
3. ### 技术够用就好。

   我们会选择能完成任务的最简单的工具。这个网站就是纯 HTML 和 CSS 写成的。环节越少，出问题的地方就越少，日后需要花的钱也越少。
4. ### 我们自己也用自己做的产品。

   [Par](https://sawirstudio.com/zh-hans/projects/par/)、[Rindraw](https://sawirstudio.com/zh-hans/projects/rindraw/)、[Squishu](https://sawirstudio.com/zh-hans/projects/squishu/) 等都是我们自己的产品。它们的发布、App Review 和客户支持都由我们亲自处理，因此我们对这些工作的了解，不只来自客户项目，更来自亲身实践。
5. ### 把实情说清楚。

   隐私政策清晰易懂，如实说明应用会发送哪些数据，不使用任何诱导性的暗黑设计。我们自己的应用如此，客户项目也是如此。

## 与我们合作

我们喜欢以伙伴的方式合作，既担任顾问，也担任技术难度较高的项目的架构师。请告诉我们您面临的问题，并尽可能多地提供您掌握的信息，这样我们可以在早期就把方向定准。

我们常用的工具有：Laravel、Livewire、Go、Swift、Flutter、React、Vue、Tailwind、PostgreSQL 和 MySQL。我们会根据项目选择，如果纯 HTML 就够用，就用纯 HTML。
