# Sawir Variation Gallery Tools

![Banner di Sawir Variation Gallery Tools](https://sawirstudio.com/assets/images/plugins/sawir-variation-gallery-tools-woocommerce-banner.webp)

Sawir Variation Gallery Tools dà a ogni variante di prodotto la sua galleria: se scegliete quella rossa, vedete le foto della rossa. Funziona in perfetta sintonia con Sawir Product Image Zoom.

[Scaricatelo gratis da WordPress.org](https://wordpress.org/plugins/sawir-variation-gallery-tools-woocommerce/)

## Cosa fa

Sawir Variation Gallery Tools for WooCommerce aggiunge un campo «Immagini aggiuntive della variante» a ogni variante nell'editor di prodotto di WooCommerce.

Quando un cliente seleziona una variante nella pagina del prodotto, le immagini salvate per quella variante vengono aggiunte alla galleria prodotto di WooCommerce.

Chi gestisce il negozio può anche esportare e importare in blocco le immagini aggiuntive delle varianti da WooCommerce > Variation Images. L'esportazione CSV include ID, SKU, attributi, ID delle immagini aggiuntive e URL delle immagini di ogni variante. L'importazione CSV può sostituire o aggiungere immagini per le righe importate.

Questo plugin funziona con Sawir Product Image Zoom for WooCommerce: https://wordpress.org/plugins/sawir-product-image-zoom-for-woocommerce/

Le immagini delle varianti vengono aggiunte come normali immagini della galleria di WooCommerce, quindi Sawir Product Image Zoom for WooCommerce può includerle nella sua lightbox e nell'esperienza di zoom.

## Domande

### Come si confronta con le alternative?

Plugin come Additional Variation Images Gallery e Iconic WooThumbs abbinano le immagini per variante a un proprio player di gallerie: slider, layout, video. Sawir Variation Gallery Tools salva le immagini per variante e le passa alla galleria standard di WooCommerce, così il vostro tema e i plugin complementari (come Sawir Product Image Zoom) continuano a funzionare senza modifiche, e chi gestisce il negozio può usare l'esportazione e l'importazione CSV per le modifiche in blocco. Se volete una nuova esperienza di galleria, scegliete una suite; se volete le immagini delle varianti dentro la galleria che avete già, questa è l'opzione mirata.

### Funziona con Sawir Product Image Zoom for WooCommerce?

Sì. Le immagini delle varianti aggiunte da questo plugin usano il markup standard della galleria prodotto di WooCommerce, quindi funzionano con Sawir Product Image Zoom for WooCommerce.

### Posso aggiornare, esportare o importare in blocco le immagini delle varianti?

Sì. Andate su WooCommerce > Variation Images per esportare un CSV o importarne uno che abbina le varianti tramite `variation_id` o `variation_sku`. Le righe da importare possono usare ID di allegati già presenti nella Libreria dei media oppure URL.
