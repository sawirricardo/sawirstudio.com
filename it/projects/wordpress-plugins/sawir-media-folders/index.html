Sawir Media Folders

Sawir Media Folders porta le cartelle nella libreria media di WordPress, tutte quelle che vi servono, con il drag and drop per archiviare i file.

Scaricatelo gratis da WordPress.org

Cosa fa

Organizzate la libreria media in cartelle e sottocartelle. Nessun limite al numero di cartelle, nessuna versione a pagamento da sbloccare.

  • Cartelle e sottocartelle illimitate: nessun tetto massimo.
  • Veloce: l'intero albero delle cartelle si carica con due sole query al database, a prescindere dalle dimensioni della libreria. Il filtraggio usa la query media nativa di WordPress.
  • Sicuro: le cartelle sono virtuali (una tassonomia). I file fisici non vengono mai spostati, quindi nessun URL smette di funzionare. Eliminare una cartella non elimina mai i file.

Domande

Come si confronta con le alternative?

FileBird, HappyFiles e Real Media Library sono plugin per le cartelle maturi, con funzioni extra ben rifinite, e le loro versioni gratuite di solito limitano il numero di cartelle che si possono creare. Sawir Media Folders mantiene un ambito ristretto (cartelle virtuali, drag & drop, filtraggio veloce) senza limiti e senza versione a pagamento. Le cartelle sono una tassonomia, quindi i file non si spostano fisicamente e nessun URL smette di funzionare. Se vi servono funzioni extra come le cartelle per singolo utente o le integrazioni con le gallerie, le versioni premium valgono il loro prezzo; se vi serve solo mettere ordine nella libreria, questo plugin resta gratuito e veloce.

Le cartelle cambiano gli URL dei miei file?

No. Le cartelle servono solo a organizzare i contenuti (una tassonomia nascosta applicata agli allegati). I file restano esattamente dove WordPress li ha caricati.

Cosa succede se disattivo o elimino il plugin?

Non si rompe nulla. I vostri file restano intatti; le assegnazioni alle cartelle semplicemente non vengono più mostrate. Se lo riattivate, tornano al loro posto.

Nella versione gratuita c'è un limite alle cartelle?

Non esiste una versione a pagamento. Tutto è gratuito e illimitato.
