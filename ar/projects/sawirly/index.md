# Sawirly

خدمة اختصار روابط تضع الخصوصية أولاً، بلا تتبّع وبروابط يمكن أن تنتهي صلاحيتها

معظم خدمات اختصار الروابط تتتبّع نقراتكم أو تعرض إعلانات أو تجمع بيانات شخصية. أما Sawirly فلا تفعل ذلك: فهي لا تسجّل عنوان IP الخاص بكم أو موقعكم أو متصفحكم، ولا تنشئ لها بصمة رقمية، وكل رابط نظيف وخاص بشكل افتراضي.

يمكن أن يكون للرابط اسم مستعار مخصص، أو أن يعمل بين تاريخ بداية وتاريخ نهاية، أو أن يعمل لنقرة واحدة فقط. خدمة Sawirly مجانية للاستخدام الشخصي، ويحصل المطورون على واجهة API نظيفة تحترم الخصوصية.
