# Ce que ce site collecte

En clair : ce que nous mesurons, ce que vous nous envoyez et qui d'autre traite ces données.

*Dernière mise à jour le 28 octobre 2026*

## Comment nous mesurons l'audience du site

Nous utilisons [Microsoft Clarity](https://clarity.microsoft.com/) pour comprendre comment le site est utilisé : quelles pages sont ouvertes, où les visiteurs cliquent et jusqu'où ils font défiler la page. Clarity enregistre aussi les sessions sous forme de replays, avec votre navigateur, votre appareil, votre localisation approximative et la page depuis laquelle vous êtes arrivé. Il peut déposer des cookies pour distinguer une visite de la suivante.

Nous consultons ces données pour repérer ce qui prête à confusion ou ne fonctionne pas, et le corriger. Nous ne les vendons pas. Microsoft traite les données conformément à sa [Déclaration de confidentialité Microsoft](https://privacy.microsoft.com/privacystatement).

## Quand vous nous contactez

Le [formulaire de contact](https://sawirstudio.com/fr/contact/) envoie votre nom, votre adresse e-mail, votre entreprise (si vous l'indiquez), votre besoin et votre message vers un Google Form de notre compte Google. Nous l'utilisons pour vous répondre et pour échanger sur votre projet. Sur simple demande, nous supprimons ces données.

## Services chargés par le site

Les polices proviennent de Google Fonts : votre navigateur partage donc votre adresse IP avec Google lorsqu'il les télécharge ([politique de confidentialité de Google](https://policies.google.com/privacy)). Le site est hébergé sur Cloudflare, qui traite chaque requête sur son trajet jusqu'à vous ([politique de confidentialité de Cloudflare](https://www.cloudflare.com/privacypolicy/)).

## Stocké dans votre navigateur

Si vous passez du mode clair au mode sombre, votre navigateur mémorise ce choix dans son stockage local. Il reste sur votre appareil et ne nous est pas transmis.

## Nos applications

Chacune de nos applications a sa propre politique de confidentialité, accessible depuis sa fiche sur l'App Store. Retrouvez-les toutes dans la rubrique [Projets](https://sawirstudio.com/fr/projects/).

## Questions

Pour toute question sur vos données, ou pour les faire supprimer, écrivez-nous via le [formulaire de contact](https://sawirstudio.com/fr/contact/).
