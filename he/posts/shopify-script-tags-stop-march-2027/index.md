# ה-Script Tags של Shopify יפסיקו לעבוד ב-1 במרץ 2027. מה כדאי לבעלי חנויות לעשות

ב-1 במרץ 2027 Shopify תפסיק להזריק script tags לחנויות אונליין. כל מה שבחנות שלכם עדיין נטען בדרך הזו, כמו ווידג'ט ביקורות, בועת צ'אט או פיקסל מעקב, פשוט יפסיק להופיע. שום דבר לא ייכשל בצורה בולטת. דברים פשוט ייעלמו.

Shopify הודיעה על כך ב-[אוגוסט 2026](https://shopify.dev/changelog/posts/online-store-script-tags-deprecation). הנה מה שזה אומר אם אתם מנהלים חנות.

## מהו script tag

script tag הוא דרך של אפליקציה להוסיף JavaScript לחנות שלכם דרך ה-API, בלי לגעת בתבנית (theme). בגלל זה אפליקציות אהבו אותו, ובגלל זה הוא גם בעייתי: script tags לא מופיעים בעורך התבנית, ולכן אי אפשר לראות אותם או לכבות אותם משם. לפעמים אפליקציות שהוסרו השאירו אחריהן script tags.

## לוח הזמנים

- **1 באוקטובר 2026:** אפליקציות לא יוכלו עוד ליצור או לעדכן script tags, בשום גרסת API. אלה שכבר קיימים ימשיכו לרוץ.
- **1 במרץ 2027:** Shopify מפסיקה לטעון script tags של החנות המקוונת.

Script tags בעמוד סטטוס ההזמנה הופסקו קודם, בלוח זמנים נפרד. אם משהו כבר הפסיק להופיע שם, זו הסיבה.

## איך בודקים את החנות שלכם

Shopify לא מספקת לבעלי חנויות רשימה של script tags, ולכן צריך לבדוק בעצמכם:

1. **רשמו את האפליקציות שמוסיפות משהו לחזית החנות.** ביקורות, צ'אט, חלונות קופצים, upsells, מועדון לקוחות, אנליטיקס, פיקסלים של פרסום. אפליקציות שעובדות רק בממשק הניהול לא מושפעות.
2. **בדקו את App embeds בעורך התבנית.** אם אפליקציה מופיעה שם והיא מופעלת, היא משתמשת בשיטה החדשה ואין בעיה.
3. **בדקו את קוד המקור של העמוד.** פתחו את החנות, הציגו את קוד המקור וחפשו `asyncLoad`. ברוב החנויות כתובות ה-URL של ה-script tags מופיעות בבלוק הזה. כל דומיין שם בדרך כלל מצביע על אפליקציה.
4. **שאלו את מפתחי האפליקציה.** “האם האפליקציה שלכם משתמשת ב-script tags, והאם היא תעבוד אחרי 1 במרץ 2027?” היא שאלה שאפליקציה מתוחזקת יכולה לענות עליה במשפט אחד.

Shopify דוחפת אפליקציות לכיוון של theme app extensions כבר שנים, ולכן רוב האפליקציות המתוחזקות היטב כבר תקינות. הסיכון הוא באפליקציות ישנות, באפליקציות מותאמות אישית שמישהו בנה לכם לפני שנים, ובשאריות של אפליקציות שאתם כבר לא משתמשים בהן.

## מה מחליף את script tags

- **App embed blocks**, חלק מ-theme app extension, לכל דבר שמוצג בעמוד. מפעילים אותם בעורך התבנית, כלומר סוף סוף אפשר לראות אותם.
- **Web pixels** לסקריפטים שרק אוספים נתוני אנליטיקס או המרות. הם רצים בסביבה מבודדת (sandbox) ולא דורשים מכם שום דבר, ברגע שהאפליקציה תומכת בהם.

## אם אפליקציה לא תעודכן

החליפו אותה לפני מרץ, או בנו מחדש את היכולת שלה. באפליקציה מותאמת אישית, העבודה היא בדרך כלל להעביר את הסקריפט ל-theme app extension, או ל-web pixel אם הוא רק עוקב. כבר כשאתם בזה, מחקו script tags של אפליקציות שהסרתם; ה-mutation בשם `scriptTagDelete` עדיין עובד.
