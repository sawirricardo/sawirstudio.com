# WordPress 7.2 יוצא ב-8 בדצמבר: מה אנחנו בודקים בתוספים שלנו

WordPress 7.2 מתוכנן לצאת ב-8 בדצמבר 2026. מועמד השחרור הראשון (RC) צפוי ב-17 בנובמבר, ובנקודה הזו רשימת התכונות ננעלת ומתפרסם ה-Field Guide, הרשימה של כל הערות המפתחים. עד אז, גרסאות הבטא הן המקום הזול ביותר לגלות שיש בעיה בתוסף שלכם.

אנחנו מתחזקים [12 תוספים חינמיים ב-WordPress.org](https://sawirstudio.com/he/projects/wordpress-plugins/), ולכן זו הרשימה שלנו עצמנו. חלק מהפריטים שלהלן עדיין היו בגדר הצעה בזמן הכתיבה; המילה האחרונה היא של ה-Field Guide.

## איך בודקים כבר היום

- **WP-CLI** באתר בדיקות: `wp core update --version=7.2-beta4`, או כל בטא או RC חדשים יותר.
- **התוסף WordPress Beta Tester**, מוגדר על “Bleeding edge” ו-“Beta/RC Only”.
- **WordPress Playground**, כדי להתנסות בדפדפן בלי להתקין כלום.

אף פעם לא באתר חי. הפעילו את `WP_DEBUG` ואת `WP_DEBUG_LOG` ושימו לב להתראות על קוד שהוצא משימוש (deprecation); שם מופיעות רוב האזהרות המוקדמות.

## מה אנחנו בודקים

### Application Passwords

בגרסה 7.2 Application Passwords מקבלים הקשחה: זיהוי טוב יותר של סביבות מקומיות ו-HTTPS, אימייל כשנוספת סיסמה חדשה, וטיפול בטוח יותר בתפקיד ברירת המחדל. אם התוסף שלכם, או הכלים של הלקוחות שלכם, מתחברים ל-REST API בדרך הזו, הריצו את התהליך מקצה לקצה.

### ה-Secrets API

דרך מובנית בליבה לשמירת פרטי גישה בהצפנה, כדי שתוספים יפסיקו לשמור מפתחות API כאפשרויות בטקסט רגיל. ההצעה הייתה להכניס אותו ל-7.2, ואת מסך הניהול לדחות ל-7.3. אם התוסף שלכם שומר מפתחות API, עקבו אחרי ה-Field Guide: כשהוא ישוחרר, שם צריכים המפתחות האלה להישמר. אף אחד מהתוספים החינמיים שלנו לא שומר היום מפתחות של צד שלישי, ולכן אצלנו זה נוגע בעיקר לעבודה עבור לקוחות.

### Sudo mode

מתוכנן: בקשה ממשתמש מחובר לאשר שוב את הסיסמה שלו לפני פעולות בעלות הרשאות גבוהות. אם התוסף שלכם מבצע פעולות כאלה מהמסכים שלו או דרך AJAX, בדקו מה קורה כשהליבה מבקשת אימות חוזר באמצע הפעולה.

### הראוטר של Interactivity API

ראוטר חדש לצפייה בניווט בצד הלקוח מחליף את הצמד `state.navigation.hasStarted` ו-`hasFinished`, שהוצא משימוש. נוספה גם הנחיית `data-wp-html` להצגת קוד HTML מהימן.

### אייקונים והתראות בממשק הניהול

ב-admin bar ובתפריט הניהול, Dashicons מוחלפים באייקוני SVG, והתראות הניהול מקבלות הקראה טובה יותר בקוראי מסך. אם התוסף שלכם מעצב את אייקון התפריט שלו או פונה למחלקות של Dashicons ב-CSS של הניהול, כדאי לראות איך זה נראה בבטא.

### DataViews ועורך האתר

תוספים יכולים לרשום מסכים משלהם בעורך האתר (Site Editor) ולשלוט מהשרת בשדות ובפריסות של DataViews. שום דבר לא נשבר כאן, אבל אם לתוסף שלכם יש מסך רשימה, כדאי להכיר את הכיוון.

## אחרי הבדיקות

עדכנו את “Tested up to” ב-readme רק אחרי שבאמת בדקתם, לא לפני. WordPress.org מציג למשתמשים אזהרה כשתוסף לא נבדק עם הגרסאות הראשיות האחרונות, והאזהרה הזו עולה בהתקנות. בתוספים שלנו כתוב כרגע “Tested up to: 7.1”; הם יעברו ל-7.2 ברגע שיעברו בהצלחה את הבדיקות על ה-RC.

גם ערכת העיצוב החדשה כברירת מחדל, Ipsum, מגיעה עם הגרסה. אם התוסף שלכם מציג משהו בחזית האתר, בדקו אותו שם; כך ייראו אתרים חדשים.

אם יש לכם תוסף שצריך עדכון ל-7.2, או תוסף מותאם אישית שאף אחד כבר לא מתחזק, [נשמח להסתכל](https://sawirstudio.com/he/contact/).
