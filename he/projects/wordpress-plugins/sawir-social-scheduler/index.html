Sawir Social Scheduler

Sawir Social Scheduler מאפשר לכם לכתוב פוסט פעם אחת ב-wp-admin ולתזמן אותו ל-27 רשתות חברתיות, עם עריכה נפרדת לכל ערוץ, שרשורים, מדיה ותצוגות מקדימות. הטוקנים של החשבונות שלכם נשארים בשרת שלכם.

הורידו בחינם מ-WordPress.org

מה זה עושה

Sawir Social Scheduler הופך את WordPress למתזמן פוסטים לרשתות חברתיות. מחברים את הערוצים באמצעות הטוקנים שכל פלטפורמה מספקת, כותבים פוסט, בוחרים ערוצים, קובעים תאריך ומפרסמים. כל שליחה רצה ברקע ומחזירה קישור לפוסט, או את הודעת השגיאה של הפלטפורמה עצמה.

אין שירות חיצוני באמצע. פרטי הגישה מוצפנים באמצעות ה-salts של האתר שלכם ואינם יוצאים מהשרת.

ערוצים

אפשר להוסיף כמה ערוצים שרוצים, כולל כמה חשבונות באותה פלטפורמה. בכל ערוץ יש כפתור Test connection שמביא את שם החשבון ואת התמונה שלו, ומוודא שהטוקן באמת עובד לפני שאתם סומכים עליו.

רשתות חברתיות: X (Twitter), Facebook Page, Instagram, Threads, LinkedIn Page, Bluesky, Mastodon, TikTok, YouTube, Pinterest, Tumblr, Dribbble, Google Business Profile

קהילות: Telegram, Discord, Slack, Reddit, Lemmy, VK, Kick, Twitch, Whop

בלוג וניוזלטר: WordPress, Medium, Dev.to, Hashnode, Listmonk

אפשר לקבץ ערוצים לפי לקוח או מותג בקבוצות מקוננות, ואז לבחור קבוצה שלמה בלחיצה אחת.

פוסטים

  • טקסט אחד, הרבה ערוצים. בוחרים ערוצים בתיבות סימון. ערוצים שלא שיניתם יקבלו את הפוסט כפי שנכתב.
  • התאמה לכל ערוץ. מסמנים “Customize” בכל ערוץ כדי לתת לו חלקים משלו: טקסט, מדיה והשהיות. הם ממולאים מראש מהפוסט, כך שאתם עורכים עותק. שאר הערוצים ממשיכים לקבל את הפוסט כפי שנכתב.
  • שרשורים. מוסיפים חלקים כדי לפרסם שרשור ב-X, Threads, Bluesky, Mastodon ו-Telegram, ולכל חלק מדיה משלו. פלטפורמות בלי שרשורים מקבלות את החלקים מחוברים יחד.
  • מדיה. מצרפים תמונות ווידאו פעם אחת, וכל פלטפורמה מקבלת את מה שהיא תומכת בו: אלבומים, קרוסלות, Reels והעלאות וידאו שניתנות להמשך.
  • תזמון. אפשר להשתמש בתאריך “Publish on” הרגיל של WordPress, או לקבוע לכל ערוץ שעה משלו.
  • שעות פרסום. קובעים לכל ערוץ את שעות הפרסום הרגילות שלו. “Next free slot” ממלא את המשבצת הפנויה הבאה, לוח השנה מציג משבצות עתידיות ריקות שאפשר ללחוץ עליהן כדי למלא אותן, וה-API מקבל "date": "next".
  • תצוגה מקדימה. תצוגה מקדימה חיה לכל ערוץ, שנראית כמו הפלטפורמה האמיתית, עם מגבלות התווים וכללי המדיה, כך שתראו בדיוק מה ייצא.
  • תגובות והשהיות. בפלטפורמות בלי שרשורים, חלקים נוספים מתפרסמים כתגובות מתחת לפוסט. כל חלק יכול להמתין מספר דקות קבוע אחרי הקודם.
  • שיתוף פוסט מהבלוג. תיבה בעורך הפוסטים הרגיל מפרסמת לערוצים שלכם כשהפוסט מתפרסם, עם טקסט ומדיה משלה.
  • שכפול. מעתיקים פוסט עם הערוצים, החלקים וההתאמות שלו כטיוטה חדשה. אפשר לשמור טיוטות כתבניות.
  • אזכורים. כותבים @handle והרשת מזהה אותו ב-X, Instagram, Threads, Mastodon, Telegram, Reddit ו-Bluesky, שם קישורים ותגיות הופכים לאלמנטים אמיתיים בפוסט. דפי חברה ב-LinkedIn נכתבים @[Name](org:12345) עם המזהה מכתובת הדף; דפי Facebook נכתבים @[12345].
  • חזרה. שולחים מחדש פוסטים נצחיים כל N ימים או שבועות, עד תאריך מסוים או מספר פעמים. כל הרצה היא פוסט נפרד עם שליחות וסטטיסטיקות משלו. כותבים {n} בטקסט כדי למספר את ההרצות, כי X, Threads ו-Bluesky דוחות טקסט זהה.

לוח שנה

כל פוסט מתפצל לשליחה אחת לכל ערוץ, ולוח השנה מציג כל שליחה ככרטיס שצבעו לפי מצבה: מתוזמן, נשלח, נכשל, מוחזק, טיוטה, בתהליך. גוררים כרטיס כדי להזיז את השעה של אותו ערוץ. לחיצה על כרטיס מציגה את השגיאה, כפתור Retry, הקישור החי ונתוני מעורבות. לחיצה על משבצת ריקה פותחת פוסט לאותה שעה. תצוגות חודש, שבוע, יום ורשימה, עם סינון לפי קבוצה וסטטוס.

אנליטיקס

לייקים, תגובות, שיתופים, צפיות וחשיפות נאספים שעה, יום ושבוע אחרי כל שליחה, וגם לפי דרישה, ב-16 פלטפורמות. מספר העוקבים נרשם מדי יום לכל ערוץ, עם גרף קטן ל-30 יום. המספרים מופיעים בכרטיסי לוח השנה, בתיבת Analytics של הפוסט וברשימת הערוצים. דף Analytics מסכם את 7, 30 או 90 הימים האחרונים בהשוואה לתקופה שלפניהם: פוסטים שנשלחו, מעורבות, חשיפה ועוקבים והשינוי בהם, גרף עוקבים, מעורבות לפי ערוץ והפוסטים המובילים שלכם.

אישור לקוח

מסמנים “Hold sends until approved”, מעתיקים את קישור התצוגה המקדימה ושולחים ללקוח. הוא רואה את הפוסט כפי שייראה בכל ערוץ, בלי התחברות, ולוחץ על Approve או על Request changes עם הערה. האישור משחרר את השליחות. כל החלטה נשמרת בהיסטוריה.

העלאות וידאו גדולות ל-X, YouTube ו-TikTok רצות בפרוסות קצרות שממשיכות בין משימות רקע, כך שהן עומדות במגבלות הזמן של האחסון ולעולם לא טוענות קובץ שלם לזיכרון.

REST API

כל מה שאפשר לעשות בממשק הניהול זמין בכתובת /wp-json/sawir-social/v1 לאוטומציות, לאפליקציות מובייל ולאתרים אחרים. ההזדהות מתבצעת עם application password; ההרשאות עוקבות אחרי היכולות של התוסף, ופרטי הגישה של הערוצים לעולם לא מוחזרים.

  • GET /platforms, GET /channels, GET /channels/{id}, POST /channels/{id}/test
  • GET|POST /posts, GET|PATCH|DELETE /posts/{id}, POST /posts/{id}/duplicate, GET /posts/{id}/analytics
  • GET /sends, GET /sends/{id}, POST /sends/{id}/retry, POST /sends/{id}/stats

יוצרים פוסט עם {"title","content","status":"future","date":"2026-12-25 09:00","media":[12],"parts":[{"text","media","delay"}],"channels":[{"id":38,"parts":[{"text","media","delay"}],"date":"…"}],"groups":["Client A"],"hold":false}. ה-parts של ערוץ מחליפים את הפוסט עבור אותו ערוץ; text הוא קיצור לחלק יחיד.

סוכני AI

אותן פעולות רשומות ב-WordPress Abilities API בשמות sawir-social/list-channels, create-post, update-post, list-posts, list-sends, retry-send, test-channel, get-analytics ו-list-platforms, עם סכמות קלט ופלט מוגדרות. כל סוכן שמחובר דרך מתאם ה-MCP של WordPress רואה אותן ככלים, ואפשר גם לקרוא להן בכתובת /wp-json/wp-abilities/v1/abilities/{name}/run. ה-Abilities API הוא חלק מ-WordPress 6.9 ואילך; בגרסאות ישנות יותר התוסף כולל אותו בתוכו, כך שהיכולות זמינות בכל מקום שבו התוסף רץ.

דרישות

השליחות רצות ברקע דרך Action Scheduler כשיש אותו באתר (WooCommerce ועוד תוספים רבים מספקים אותו), ואחרת דרך WP-Cron. ב-cron המובנה של WordPress הן מתקדמות רק כשיש תנועה באתר. לשליחה מיידית, הוסיפו cron של המערכת; מסך Calendar מציג את הפקודה המדויקת לאתר שלכם.

בפלטפורמות שמושכות מדיה לפי כתובת URL (Instagram, Threads, Facebook, Pinterest, Telegram), המדיה חייבת להיות נגישה מהאינטרנט. אתר פיתוח מקומי לא יכול להעביר אליהן תמונות.

קרדיטים

כולל את FullCalendar (MIT), את ספריית WordPress Abilities API (GPL) ואת סמלי המותגים של Simple Icons (CC0). משתמש ב-Action Scheduler כשתוסף אחר מספק אותו.

צילומי מסך

שאלות

מאיפה משיגים את הטוקנים?

בהגדרות המפתחים של כל פלטפורמה. טופס הערוץ מציין בדיוק איזה פרט גישה נדרש, למשל Facebook Page access token, טוקן של בוט Telegram או Bluesky app password. עדיף להשתמש בטוקנים ארוכי טווח; טוקנים של Meta ושל LinkedIn פגים אחרי כ-60 יום וצריך להדביק אותם מחדש.

בבדיקת Telegram מופיע “chat not found”

לערוצים פרטיים אין @username. השאירו את שדה Chat ID ריק ולחצו על Test connection: התוסף יציג את כל הצ'אטים שהבוט נוסף אליהם, עם המזהה המספרי להדבקה.

למה שליחה נתקעת על “In progress…”?

תור הרקע עדיין לא רץ. היכנסו לאתר, או הגדירו את ה-cron של המערכת שמוצג במסך Calendar.

אפשר לפרסם וידאו ב-Instagram מאתר מקומי?

לא. Instagram מושך מדיה לפי כתובת URL ודורש כתובת ציבורית. כל שאר היכולות של התוסף עובדות גם מקומית.

משתלב היטב עם

  • Sawir Insights: מראה איך מבקרים משתמשים באתר שלכם, עם מפות חום, הקלטות סשן, סקרים, משפכי המרה וניתוח טפסים, ושומר את כל המידע על השרת שלכם.
  • Sawir Live Translate: מתרגם את הדפים שלכם במקום שבו הם נמצאים: בוחרים שפה, מתרגמים אוטומטית את מה שמוצג, שומרים, ונותנים למבקרים בורר שפות.
