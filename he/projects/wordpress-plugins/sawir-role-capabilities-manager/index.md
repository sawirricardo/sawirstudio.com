# Sawir Role Capabilities Manager

![באנר של Sawir Role Capabilities Manager](https://sawirstudio.com/assets/images/plugins/sawir-role-capabilities-manager-banner.webp)

Sawir Role Capabilities Manager מאפשר לכם ליצור תפקידי משתמשים משלכם ולקבוע במדויק מה כל תפקיד יכול לעשות, בין אם הוא חדש ובין אם מובנה.

[להורדה חינם מ-WordPress.org](https://wordpress.org/plugins/sawir-role-capabilities-manager/)

## מה זה עושה

Sawir Role Capabilities Manager מוסיף מסך הרשאות תפקידים, זמין למנהלי המערכת בלבד, תחת "משתמשים". מנהלי המערכת יכולים ליצור תפקידים, להעתיק הרשאות מתפקידים קיימים, להוסיף מפתחות הרשאה מותאמים אישית ולנהל הרשאות בתפקידים קיימים.

## שאלות

### איך זה משתווה לחלופות?

User Role Editor, Members ו-PublishPress Capabilities הם הכלים המוכרים בתחום, וגרסאות ה-Pro שלהם מוסיפות הגבלת תוכן, הגנה בצד הלקוח ושליטה בתפריט הניהול. Sawir Role Capabilities Manager מכסה בחינם את המשימה הניהולית הבסיסית במסך אחד תחת "משתמשים": יצירת תפקידים, העתקת הרשאות בין תפקידים, הוספת מפתחות הרשאה מותאמים אישית ועריכת תפקידים קיימים. אם אתם צריכים להגביל תוכן או לבנות רמות חברוּת, כדאי לפנות ל-Members או ל-PublishPress. אם אתם צריכים ניהול נקי של תפקידים והרשאות, זה מספיק.
