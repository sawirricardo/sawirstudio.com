# Sawir Live Translate

![באנר של Sawir Live Translate](https://sawirstudio.com/assets/images/plugins/sawir-live-translate-banner.webp)

Sawir Live Translate מתרגם את הדפים שלכם במקום שבו הם נמצאים: בוחרים שפה, מתרגמים אוטומטית את מה שמוצג, שומרים, ונותנים למבקרים בורר שפות.

[להורדה חינמית ב-WordPress.org](https://wordpress.org/plugins/sawir-live-translate/)

## מה זה עושה

פותחים כל דף באתר, לוחצים על "Translate this page" בסרגל הניהול, בוחרים שפת יעד, ואז מתרגמים אוטומטית כל מחרוזת גלויה (באמצעות שירות תרגום מכונה חינמי) או עורכים תרגומים ידנית, תוך כדי צפייה בעדכון הדף בזמן אמת.

התרגומים השמורים מוטמעים בצד השרת בתגובת ה-HTML (ידידותי ל-SEO: בלי הבהוב של טקסט לא מתורגם, ועם תגיות hreflang חלופיות ב-head), והמבקרים עוברים בין שפות באמצעות בורר שפות מבוסס קישורים (בפינה הימנית התחתונה).

הכתובות משתמשות בקידומת שפה בנתיב, למשל /es/about לספרדית, ו-/about לשפת המקור (שנשארת הכתובת הקנונית, ללא קידומת). השפה נקבעת לפי הסדר הבא: נתיב /es/ ← ?lang=es ← עוגייה שמורה ← Accept-Language של הדפדפן ← שפת המקור. בכתובות של דף הבית ובכתובות ללא קידומת, שפת הדפדפן של המבקר מזוהה אוטומטית וללא הפניה (נשלחת כותרת Vary כדי שמטמונים משותפים יתנהגו כראוי).

1. הגדרות ← Live Translate: מגדירים את שפת המקור ומסמנים את השפות להצעה. 2. נכנסים לדף בצד הציבורי של האתר ולוחצים על "🌐 Translate this page" בסרגל הניהול. 3. בוחרים שפה, לוחצים על "Auto-translate empty" (או עורכים מחרוזות), ואז על "Save". 4. המבקרים משתמשים בבורר השפות (בפינה הימנית התחתונה), ולכל שפה יש כתובת /xx/ משלה.

שימו לב: קידומות השפה בנתיב מניחות התקנה בדומיין הראשי, וכן שאין דף ברמה העליונה שה-slug שלו הוא קוד שפה בן שתי אותיות.

## שאלות

### איך זה משתווה לחלופות?

פלטפורמות רב-לשוניות כמו WPML, Polylang ו-TranslatePress מתייחסות לתוכן מתורגם כחלק מרכזי ממבנה האתר, עם תהליכי עריכה לכל שפה, שירותי תרגום ואינטגרציה עמוקה עם בוני דפים ועם WooCommerce. Sawir Live Translate קל יותר במכוון: פותחים דף, מתרגמים את מה שמוצג (אוטומטית או ידנית), ומגישים אותו מכתובת עם קידומת שפה ועם תגיות hreflang. אם אתם בונים אתר רב-לשוני מלא, עם תפריטים, מוצרים ותהליכי עריכה מתורגמים, השתמשו באחת מהפלטפורמות האלה. אם אתם רוצים שדפים קיימים יהיו קריאים בשפה אחרת עוד היום אחר הצהריים, זה בדיוק מה שהתוסף הזה עושה.

### אני מחליף שפה אבל שום דבר לא משתנה

כמעט תמיד זה אומר שעדיין לא נשמרו תרגומים לאותה שפה. בדקו ב-Settings → Live Translate → Saved translations: אם השפה לא מופיעה ברשימה (או שמוצג לידה 0 מחרוזות), פתחו שוב את עורך הדף, תרגמו אוטומטית ולחצו על Save. התצוגה המקדימה החיה בעורך לא נשמרת עד שתעשו זאת.

### חלק מהמחרוזות נשארות לא מתורגמות

העורך בתוך הדף רואה רק את המחרוזות בדף שפתחתם. טקסט שנמצא בדפים אחרים מחייב לתרגם גם את אותם דפים, או להריץ את הסריקה של כל האתר. מחרוזות שמוזרקות על ידי סליידרים או סקריפטים אחרי טעינת הדף עשויות לדרוש הזנה ידנית דרך "Edit all site strings".

### ערכתי את התוכן והתרגום שלו נעלם

התרגומים מותאמים לטקסט המקורי המדויק. אם ניסחתם משפט מחדש, תרגמו את הגרסה החדשה פעם אחת ושמרו.
