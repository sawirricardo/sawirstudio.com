# Sawirly

מקצר קישורים שמעמיד את הפרטיות במקום הראשון, בלי מעקב, ועם קישורים שיכולים לפוג

רוב מקצרי הקישורים עוקבים אחרי הקליקים שלכם, מציגים פרסומות או אוספים מידע אישי. Sawirly לא עושה את זה: הוא לא שומר ולא יוצר טביעת אצבע של כתובת ה-IP, של המיקום או של הדפדפן שלכם, וכל קישור נקי ופרטי כברירת מחדל.

לקישורים אפשר להגדיר כינוי מותאם אישית, לקבוע להם תאריך התחלה ותאריך סיום, או להגביל אותם ללחיצה אחת בלבד. Sawirly חינמי לשימוש אישי, ולמפתחים יש API נקי שמכבד פרטיות.
